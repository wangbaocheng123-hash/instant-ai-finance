# 指定视频采集验收（1.0.7）

2026-09-05：按所有者截图，在北京博主采集端的当前博主设置中增加“指定一条视频”。
本次不继续处理模型下载器的 30 天登录，也不改变原有按数量抓取和自动调度规则。

## 已实现

- 粘贴抖音短链接、完整视频地址或分享文案后自动识别作品编号；识别不启动 Chromium。
- 点击“只抓取这条视频”并确认后，按当前博主的评论开关和数量上限处理这一条。
- 填写链接时，原来的“保存并抓取”和“补抓评论”按钮也明确绑定到这一条，防止误抓最近 50 条。
- 沿用串行浏览器锁、下载与音视频合并、按作品 ID 去重、评论合并以及现有 outbox 回调。
- 不扫描主页、不更改实时采集游标；重复抓取不重复下载，能够补抓指定作品评论。
- 无效、主页、多条或其他站点链接直接拒绝；短链接逐跳校验，失败不降级为批量任务。

- 完整 Python 测试 221 项：219 项通过、2 项原有跳过。
- 实际浏览器通过真实本机 HTTP 服务验证：自动识别不采集、取消确认、按钮正确绑定作品、
  无效链接、重新打开清空、当前博主归属、390/320 像素手机宽度及无 JavaScript 错误。
- 所有者提供的公开短链接解析为作品 `7678988051075051365`。
- 在隔离本机目录通过真实单条采集流程下载《35的紫金矿业包含了什么？》，
  文件 24,053,399 字节、493.68 秒，MP4 画面与声音轨道均通过校验。
- 真实视频测试没有抓取评论、调用 AI、修改线上博主数据或向新加坡发送验收文件；
  评论和传输回调通过隔离的流程测试验证。
