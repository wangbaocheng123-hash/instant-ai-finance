# 北京模型下载器

本目录是北京采集套件中的真实模型下载器程序。它从北京服务器当前运行的
`0.8.1+login30d.05287e9f6c06` 版本做受控源码导入，只包含程序、依赖声明、服务模板和
测试；数据库、视频、评论 JSON、浏览器登录资料、Cookie、`.env`、日志和备份均保留在
Git 外。

模型下载器与博主采集器共用当前仓库和北京生产分支，但保持独立进程、配置、数据目录、
发布判断和回滚。模型下载器全天 24 小时运行，以每轮主页检查开始时间为基准，每 1 分钟
检查一次模型先生主页；只在发现新作品时下载。该 1 分钟业务策略固定在代码中，旧环境变量
`MODEL_DOWNLOADER_INTERVAL_MINUTES` 不再覆盖它，因此部署时不需要手工修改北京 `.env`。
新视频扫描和下载具有硬优先级，期间绝不抓取评论。评论和手工修复只在下一次主页检查前的
空档中每次处理一项，到点强制让路；评论刷新仍按抖音实际发布时间计算：未满 24 小时每
15 分钟，达到 24 小时及以后每 60 分钟，只在成功保存后推进
`comments_collected_at`。发布器还必须在新进程启动后看到一次真实成功主页检查，不能再把
“进程处于 active”误当成采集正常。

运行测试：

```bash
python3 -B -m unittest discover -s tests -p 'test_*.py'
```
