# ADR-0003：永久采用单机单用户且不建立账户层

- 状态：`SUPERSEDED_BY_ADR_0020`
- 日期：2026-08-23
- 决策者：用户

## 背景

本产品仅供电脑所有者本人使用，不向其他人提供。为假想的其他用户增加身份、设置和权限层会扩大界面、数据库、安全与维护成本。

## 决定

1. “即时 AI”永久按单机、单用户运行。
2. 不建立注册、登录、姓名、邮箱、头像、个人资料、团队、成员、角色、权限、租户、管理员或用户管理功能。
3. 不建立用户表、用户偏好中心或多租户数据隔离抽象。
4. 仅保留程序运行必需的本机技术配置：来源、路径、模型、通知、sidecar 和运行状态；这些配置不绑定用户身份。
5. Git 本地检查点使用仓库专用占位身份，不记录用户姓名或邮箱。

## 影响

- 本地 API 默认只监听 localhost，以操作系统登录会话和本机文件权限作为边界。
- UI 不出现账户、个人中心、切换用户、成员管理或权限设置页面。
- 数据模型不含 `user_id`、tenant 或角色权限字段，除非某个上游私有数据库内部必需且不进入正式 schema。
- 若未来确需向他人提供产品，必须由用户明确推翻本 ADR，并重新进行安全、许可证和数据迁移设计；当前不得为此预留代码。

## 替代关系

用户于 2026-08-30 明确要求单一主人登录和 30 天会话。ADR-0020 替代本 ADR 中“不得登录”的部分；单主人、无注册、无个人资料、无角色权限、无租户和无多用户抽象的边界继续有效。
