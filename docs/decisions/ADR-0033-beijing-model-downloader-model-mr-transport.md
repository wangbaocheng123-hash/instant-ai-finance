# ADR-0033：北京模型下载器复用博主通道进入新加坡模型先生资料库

- 状态：`ACCEPTED`
- 日期：2026-09-03
- 决策者：产品所有者

## 背景

北京服务器的模型下载器已经独立负责模型先生抖音视频、评论和本地管理；新加坡即时 AI 已有独立模型先生资料库、手机页面与五工具只读 MCP。北京博主采集端到新加坡博主资料域的 `blogger-transfer/v1` 已正式运行，具备 HTTPS、HMAC、nonce、防重放、持久 outbox、artifact 摘要校验、幂等、退避和回执。此前 ADR-0026 明确模型下载器不自动成为发送端；所有者现进一步要求：模型下载器只要完成下载，就复用现有博主传输通道，把资料直接交给即时 AI 的模型先生模块。

仓库中另有一套早期模型下载器同步脚本，使用独立 Bearer 目标和媒体 URL；它没有接入当前即时 AI 生产端，也会引入第二套传输凭据和边界。此次不启用该旧路径。

## 决定

1. 北京原模型下载器继续独立运行、独立采集和保存，代码、数据库、媒体、服务与管理页面均不迁移、不清理、不接管。新能力放在现有北京博主采集服务中，作为只读 `ModelDownloaderBridge` 旁路。
2. 桥接器只以 SQLite `mode=ro` 读取 `/var/lib/model-downloader/library.sqlite3`，并只读取 `/srv/model-downloader/videos` 下已经完成的 MP4。它不访问抖音、不启动 Chromium、不修改模型下载器数据库、不调用豆包/ASR/AI。
3. 桥接器每 15 秒执行一次轻量元数据变化检查；没有变化时不复制文件、不新增队列、不发网络请求。发现新视频或评论修订后，媒体通过硬链接或流式复制进入博主持久 artifact 目录，评论转换为冻结的 21 字段 `blogger-comments/v1+ndjson` gzip 包。
4. 模型先生传输使用固定保留 creator ID `732ceafb-2bb3-5042-b303-967bdcf4312d`。除该身份外，清单、artifact 和 complete 全部复用现有 `blogger-transfer/v1`、同一北京节点、同一 HMAC 对等配置、同一持久 outbox、重试和回执，不增加端口、域名、Token、数据库直连或第二套公网通道。
5. 新加坡 complete 先按 ADR-0025 重新验证所有 artifact 的安全路径、长度和完整 SHA-256，再调用模型先生投影器。普通博主传输仍只完成原流程，不受影响。
6. 投影器只接受保留 creator ID、`transport_completed` 状态、已核验 MP4 和完整评论包。它再次限制评论条数与解压后体积，并将内容写入独立 `/var/lib/instant-ai/model-mr`；博主账本只作为传输审计，不成为模型先生查询源。
7. 来源作品 ID 与来源 revision 通过 Git 外 `beijing-transfer-map.json` 幂等映射。若新加坡已有相同抖音 URL，优先复用原作品编号；否则从 1,000,000 起分配新编号，避免与历史本地编号冲突。媒体按来源 ID 和摘要命名，冲突不覆盖。
8. 后续评论或媒体修订可以更新来源字段，但必须保留主人修改标题、正式视频原文、已有转写、投资解读、关键词和评股。投影动作不自动触发豆包、普通 ASR、AI 问答或任何费用。
9. 保留 creator ID 在即时 AI 的普通博主列表、详情与博主 MCP 中统一排除，避免出现一个假的“模型先生博主”。写入同一模型先生快照和详情后，现有 `search_model_mr_works` 与 `get_model_mr_work_text` 会在下一次按需查询时自然发现新作品，不建立新插件或第二个 MCP。
10. `blogger-collector.service` 通过 `SupplementaryGroups=modeldownloader` 获得最小只读权限；密钥、数据库、视频、评论、状态和映射仍全部位于 Git 外。代码仓库只保存实现、测试和配置模板。
11. 正式启用顺序固定为：先发布新加坡即时 AI 0.19.1 接收/投影端，再更新北京 1.0.5 服务与补充组，最后选一条作品做脱敏端到端验收。逆序启用会让保留身份暂时进入博主资料域，因此禁止。
12. 本决定替代 ADR-0026 中“模型下载器不自动成为协议发送端”的旧边界；其他双服务并存、资料隔离和正式发布门禁继续有效。时变罗盘不属于本链路。

## 验收

- 北京测试必须证明：下载完成的视频只入队一次；评论或元数据变化生成更高 revision；媒体始终限制在模型下载器根下；outbox 使用保留身份和现有 artifact 契约。
- 新加坡测试必须证明：只有 complete 且 artifact 二次校验成功后才投影；视频与评论可在模型先生页面读取；重复 complete 幂等；来源修订保留主人内容；保留身份在博主页面和博主 MCP 中不可见；模型先生 MCP 可检索新作品。
- 完整回归、Vite 构建、依赖审计和项目记忆检查必须通过。正式启用后只报告非敏感状态、作品编号、数量和错误代码，不输出密钥、Cookie、绝对运行路径或评论正文。

## 回滚

- 北京侧关闭 `MODEL_DOWNLOADER_BRIDGE_ENABLED` 或回退服务版本即可停止新增投递；不得删除模型下载器数据库、媒体或博主 outbox。
- 新加坡侧回退应用版本只停止新的自动投影；已写入的模型先生资料保持不变，不自动删除视频、评论、主人标题或原文。
- 如投影失败，complete 返回通用可重试错误，现有发送器按原退避机制重试；禁止绕过摘要校验、手工改数据库或改用旧 Bearer 同步脚本。
