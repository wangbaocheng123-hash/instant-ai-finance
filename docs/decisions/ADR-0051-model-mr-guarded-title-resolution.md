# ADR-0051：模型先生缺失标题的封面识别与原文兜底

- 日期：2026-09-12
- 状态：`ACCEPTED_AND_IMPLEMENTED_RELEASE_AUTHORIZED`
- 目标版本：0.22.0
- 决策者：产品所有者

## 背景

模型先生的部分抖音作品没有来源标题，北京下载器只能保存“抖音作品_编号”等占位文字；真实主题往往写在视频开头画面中。现有系统已经用豆包 ASR 生成正式视频原文并在另一次文本调用中提炼十类关键词。所有者要求恢复画面标题识别能力，并在画面仍无标题时让关键词提炼同时返回一个原文标题；同时明确禁止把视频字幕 OCR 结果当成或拼入视频原文。

## 备选方案

1. 把全片字幕 OCR 当视频原文：容易混入水印、按钮、跳变字幕和识别错误，且违背所有者明确要求。
2. 为标题新增独立模型调用：实现直接，但每条无标题作品会增加一次费用和一次失败面。
3. 只在真实来源标题无效时，把少量开头画面附到既有关键词请求；画面能确认标题就逐字采用，不能确认则由同一请求根据 ASR 正式原文拟题。

采用方案 3。

## 决定

1. 标题优先级固定为：人工标题 > 有效抖音来源标题 > 可靠封面标题 > 根据视频原文生成的 AI 标题 > 来源占位标题。人工标题永不被自动流程覆盖；来源后来补出有效标题时，可以替换封面或 AI 临时标题。
2. 只有来源标题为空或匹配明确的占位格式，才启动自动标题逻辑。有效来源标题不会提取画面、不会请求 AI 标题，也不会被覆盖。
3. 从新加坡已经验收落盘的本地视频临时提取 0、0.35、0.8、1.2 秒四张缩放 JPEG。图片只存在于一次临时目录和一次模型请求中，最多四张、单张不超过 1.5MB；完成后立即删除，不写入 Git、资料库或传输账本。
4. 开头画面作为标题证据附在原有十类关键词请求中，不增加第三次“标题模型”调用。模型只把多帧中清楚、稳定、作为主题出现的醒目大字视为封面标题；底部跳变口播字幕、用户名、按钮、水印、时间和免责声明不得作为封面标题。
5. 封面结果只有在返回来源为 `cover`、确实附有画面且置信度至少 0.8 时才可保存为 `cover_ocr`。如果没有画面或没有可靠封面标题，模型只能根据 ASR 已保存的正式 `video_original` 拟定准确中文标题，保存为 `ai_video_original`；无法可靠拟定则保留占位标题。
6. 十类关键词仍然只能来自 `video_original`。开头画面文字不进入关键词来源，连续视频字幕 OCR 不进入此流程；任何画面 OCR 文本都绝不创建、补充、覆盖或拼接正式视频原文。正式视频原文继续只由既有语音 ASR 或主人编辑产生。
7. 标题与关键词结果先进入既有 Git 外处理缓存，再以“预期占位标题仍未变化”的并发条件保存。模型调用期间若主人或来源改了标题，自动结果丢弃；任务中断后的缓存重放也遵守同一条件。
8. 继续沿用 ADR-0036/0043 的单工作者、共享提供器锁、每日最多 20 次、单视频最多 20 分钟、模糊付费结果不自动重试和不扫描完整历史库规则。本功能只作用于既有的新到视频自动任务和主人明确确认费用的单条关键词任务。
9. 北京只读桥、模型下载器扫描优先级、评论采集和传输协议均不改变。开头帧在新加坡处理端从已接收视频产生，避免给北京三分钟视频扫描增加负担。

## 数据、安全与费用边界

- 视频、开头帧、模型响应、标题元数据、原文、关键词、队列和调用记录继续保存在 Git 外；Git 只保存代码、契约和测试。
- 请求只包含 ASR 正式原文与有界开头画面，不包含评论、持仓、基金、投资解读、服务器路径、来源账号标识或凭据。
- 一条同时缺原文和关键词的新视频仍最多经历原有两类付费阶段：一次 ASR、一次关键词/标题请求；不存在独立的第三次标题调用。
- 本地开发和回归测试全部使用模拟供应商与合成媒体，真实付费调用为 0 次，也没有读取或批量改写生产作品。

## 验收

- 占位标题作品会在同一次关键词请求中附上最多四张开头画面；可靠封面标题保存后，视频原文逐字不变，字幕列表不增加。
- 无可用画面时，关键词请求仍可根据正式视频原文返回标题；低置信度封面结果不保存。
- 有效来源标题不提取画面、不接收 AI 标题；调用期间出现的人工标题不被覆盖。
- 后续占位来源修订保留封面/AI 标题，后续有效来源标题替换它；人工标题在所有来源修订中保持不变。
- 调用账本仍只有 `asr` 与 `keywords` 两个阶段；完整 Python、前端契约、生产构建、依赖审计和泄漏检查在候选发布前通过。

## 替代关系与回滚

本决定只替代 ADR-0036 中“关键词请求只发送正式原文、绝不发送标题相关画面”的局部输入约束；其关键词必须只取正式原文、费用、并发、缓存、人工核对和安全条款继续有效。ADR-0043 的自动到达、补偿和历史边界继续有效。

回滚应用代码即可停止新标题生成。不得删除已保存的人工、来源、封面或 AI 标题，也不得把画面文字回填进视频原文；旧客户端会继续把新标题当普通标题显示。
