# ADR-0078：首期知识表与社区自有图片图集

- 状态：`ACCEPTED / DEVELOPMENT CANDIDATE / NOT YET RELEASED`
- 日期：2026-10-16
- 决策者：产品所有者

## 背景

所有者要求尺寸系列使用资料真实标题，并把其有权托管的抖音图片作品原图保存到社区云端，访客不再依赖外站跳转。ADR-0076已经决定统一知识模型和Git外存储，但此前只有静态外链清单，尚无实际表、文件导入或公开资源读取。

## 决定

1. 首期直接在既有`community.sqlite3`创建版本化`knowledge_items`、`knowledge_sources`、`knowledge_measurements`、`knowledge_assets`和`knowledge_relations`，不建立只服务尺寸栏目的孤立数据库模型。
2. 现有微信尺寸清单作为Git管理的已发布来源种子进入统一表；显示原标题和来源链接，但无法访问原文时不推断标题、正文或尺寸。
3. 所有者明确要求托管的图片作品可由受控服务器侧导入器加入。原图按随机资源ID写入`/var/lib/sunmao-community/knowledge/originals/images/<asset-id>/`，元数据记录来源、授权范围、摘要、SHA-256、大小、版本和公开级别；文件不进入Git。
4. 浏览器只读取`published`条目和`public`资源。文件经`/api/size-assets/<asset-id>`返回，不接受文件路径；草稿、私有资源、缺失文件和非法ID统一不可访问。
5. 尺寸型先从同源`/api/size-resources`显示外链卡和社区图集。该接口不是通用检索；受保护后台、草稿审核、备份恢复与AI问答继续按P2-SUNMAO-13/14后续实现。
6. 当前只形成0.3.9开发候选。没有真实标题或原图的3篇微信文章和抖音作品不发布占位内容；正式创建北京目录、导入原图和公网启用仍需社区发布授权与真实资料。

## 验收

- 首条尺寸资料显示已核实标题，不再出现“微信文章01”。
- SQLite包含统一知识表和迁移版本；现有交流、统计表不被重建或清空。
- 合法图片导入后位于Git外随机资源目录，公开API不泄露文件系统路径；目录穿越、私有或未发布资源不可读取。
- 前端能同时安全渲染微信外链和同源图片图集，仍只用DOM文本属性而非HTML注入。
- 完整社区测试通过；未经正式发布指令不推进`sunmao-production`，不操作并列系统。
