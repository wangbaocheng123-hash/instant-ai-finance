# ADR-0009：个人手机版与阿里云独立副本

- 状态：`ACCEPTED`
- 日期：2026-08-28
- 决策者：用户明确要求把“即时 AI”调整成手机版、放到本人已登录的阿里云，并提供即时打开方式

## 背景

即时 AI 0.6.0 已是 Windows 本地客户端，正式数据库、原文、证据、备份、图片缓存和日志都在 `H:\即时AI文件库`。用户现在希望在手机上随时打开同一类全球财经文字资讯，但项目仍必须保持个人单用户、无产品账户、不开视频流、不绕过付费墙，也不能为了方便访问而把本机正式资料库直接暴露到公网。

## 决定

1. Windows 客户端继续作为正式桌面端；在同一展示分叉中加入手机响应式布局和可安装 Web App 外壳，不另造原生 Android/iOS 工程。
2. 手机版采用单列新闻流、触控尺寸控件、横向频道栏、底部五个快捷频道和全屏新闻详情。桌面布局在宽屏下保持不变。
3. 云端运行一个独立采集副本，继续使用相同的公开来源、规则和五分钟自动采集，但数据根目录固定为 `/var/lib/instant-ai`。它不上传、挂载或同步 `H:\即时AI文件库`，也不把云端副本当作桌面正式库的备份。
4. Python 服务在云服务器上仍只监听 `127.0.0.1:18765`；公网入口必须由 Nginx 反向代理提供 HTTPS，并使用单一的服务器级访问口令。该口令只是本人访问边界，不引入注册、邮箱、个人资料、角色或多用户账户层。
5. Web App 清单、图标和 Service Worker 只缓存静态应用外壳；所有 `/api/` 请求始终走网络，避免手机读取过期新闻数据。
6. 只部署到用户确认的既有 ECS 或轻量应用实例，不自动购买新资源，不覆盖已有站点。端口 `18765` 不进入安全组公网规则。
7. HTTPS 地址验收后，手机浏览器可使用“添加到主屏幕”，生成名为“即时 AI”的图标，作为即时打开方式。

## 理由

响应式 PWA 可以复用已经验证的 World Monitor AGPL 展示分叉、Python API 和采集规则，避免再维护一套原生手机代码。云端独立采集把可移动访问和本机正式档案隔离开：即使云实例被删除或重建，也不会损坏 H 盘的个人投资资料库。HTTPS、回环监听和服务器级口令共同避免把个人阅读状态与来源控制直接公开到互联网。

## 影响

- 桌面端和云端副本的已读、收藏、标题翻译缓存和图片缓存相互独立；本阶段不做双向同步。
- 云端会额外访问同一批公开 Feed，仍受来源速率、版权、付费墙和匿名翻译服务额度约束。
- 没有域名/证书或未确认目标实例时，可以完成代码与部署包，但不得用裸公网 HTTP 冒充安全交付。
- 未来若要同步收藏或 H 盘正式证据，必须另建加密、可审计的数据协议并新增 ADR，不能直接复制整个数据库到公网服务器。

- 手机布局与交互：`forks/InstantAI-WorldMonitor/src/instant-ai/styles.css`、`InstantFinanceApp.ts`
- 可安装外壳：`forks/InstantAI-WorldMonitor/public/manifest.webmanifest`、`sw.js`、`app-icon.svg`
- 展示分叉提交：`f3fad86eb4ec75983c6b24830f14120a4cb84606`
- 云端服务模板：`deploy/aliyun/instant-ai.service`
- HTTPS 入口模板：`deploy/aliyun/nginx-instant-ai.conf`
- 2026-08-28 本机 390×844 验收：3566 条情报、20/20 来源健康；新闻原图、全屏详情和五个底部快捷频道均正常。

## 关系

本 ADR 扩展 ADR-0004 的产品形态和 ADR-0008 的自动采集运行方式；不改变 H 盘正式库、单用户、无应用账户、无自动交易和不绕过付费墙的长期边界。
