# ADR-0034：模型先生关键词分类与投资思路作品关联

日期：2026-09-04。状态：开发验收完成，生产未发布。

## 问题与事实

0.19.2 云端作品摘要最多保留 12 个关键词，客户端只展示 3 个。投资思路仅导出分类目录，未带上作品与分类关系，手机展示为不可点击的文字。云端不是丢失所有关键词：对照时 408 条作品中 367 条有扁平关键词，但没有关键词分类；本地已有 398 条作品、367 条非空关键词、61 个分类和 363 条关联作品。

## 数据与交互决定

- 延续 ADR-0022/0023 单主人资料边界，以独立实现的数据白名单保留 `keyword_info`（10 类、每类最多 8 词、合计最多 80 词）、`keyword_revision` 和 `thought_links`。不复制模型先生本地源码，不修改本地应用。
- `/api/model-mr/thoughts/{id}/works` 返回分类、摘要、关键词与分页（默认 24，最多 100）、关联是否已导入以及缺失说明。一级分类聚合其二级分类；关键词/标题搜索；不读取所有作品详情或视频。
- 手机分类使用可聚焦的真实按钮和至少 44px 点击区域，支持返回上级、搜索及加载更多。作品卡、播放器、原文、评论共用；异步分页完成不能抢回其他标签页。
- `/api/model-mr/works/{id}/keywords` 仅允许既有主人登录和同源防护，保存前检查 `expected_revision`，冲突不覆盖。只手动整理已保存结果，不调用模型。以后北京传输修订继续保留主人修改。失败时保留编辑框草稿。
- 新增“解读感悟”展示已有内容。AI 关键词栏目明确显示已有结果，未实现或启用新的云端付费关键词生成、批处理、定时器或采集功能。分类增删/人工调整作品归类不在本轮实现内。
- 原五个公网只读 MCP 工具、OAuth 和评论/媒体鉴权边界保持不变。

## 安全迁移与预览

`scripts/model-mr-metadata.py export --output <Git外新文件>` 只 GET 固定本机 8787 的视频摘要和投资思路接口；导出正式标题（active_title）、已有关键词、公开作品链接、发布时间和分类关系。不导出路径、raw_json、数据库、粉丝隐私、媒体或凭据。

`prepare --source <当前云端索引> --package <元数据包> --output <Git外全新预览目录>` 不修改来源；必须编号+作品链接一致，或无链接时编号+正式标题+时间一致，亦支持唯一同作品链接的 ID 映射。不仅凭标题猜测。任何未匹配项、分类冲突、缺失详情、并发来源变化都拒绝准备。保留云端独有作品和已手工修改的关键词，只调整明确匹配的元数据字段。

本轮生产源校验后生成独立预览，398 条全部匹配；408 条作品保持，367 条非空分类关键词、363 条关联、61 类。索引除关键词字段外完全相同，408 份详情的原文、评论、解读等其他字段均相同。由于生产可能继续收视频或改标题，**预览不是可直接覆盖生产的发布包**。正式发布需主人另行授权，重新从最新生产状态合并、锁定写入窗口、备份、校验并可回滚。旧 `update-model-mr-owner-metadata.sh` 限定 0.15.0 且全量替换，不能用于本轮增量合并；本轮未调用或修改它。
