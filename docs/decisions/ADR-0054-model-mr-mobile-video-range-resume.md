# ADR-0054：模型先生手机视频分段续播与私有媒体缓存

- 日期：2026-09-20
- 状态：`ACCEPTED / IMPLEMENTED / RELEASED`
- 目标版本：即时 AI `0.23.1`
- 决策者：产品所有者

## 背景与根因

所有者在 iPhone 上播放模型先生本地视频时，视频经常播到中途停住，重新点击第二次或第三次后才可能完整播放。只读核对生产服务后确认 CPU、内存、进程状态均正常，问题不在手机性能或视频是否存在，而在媒体传输链路的三项叠加：

1. HTTP 服务为了防止普通请求长期占用连接，接收连接时统一设置 30 秒 socket timeout；Python socket 的这个超时同时约束发送。iPhone 播放器暂停读取或网络短时变慢时，视频写入可能在 30 秒后被截断。
2. 对 `Range: bytes=N-` 的开放区间请求，旧服务会从 N 一直发送到文件末尾，单条响应持续时间过长，放大了移动网络背压和超时问题。
3. 模型先生视频原来位于 `/api/`。生产 Caddy 对全部 `/api/*` 统一追加 `Cache-Control: no-store`，覆盖了应用希望使用的私有媒体短期缓存；用户再次点击时只能依赖重新读取。页面又只监听最终 `error`，没有显示 `waiting` 或 `stalled` 状态，所以中途停顿看起来像完全卡死。

云盘使用率 97% 是另一项容量风险，会影响后续新视频、备份或临时文件写入，但现有视频中途停住的直接原因是上述传输超时与分段策略，不把两者混为一谈。

## 决定

1. 普通 API 继续使用 30 秒连接超时，避免放宽整个服务的资源边界；只有已通过主人认证、已经开始返回的私有媒体正文，发送窗口临时提升到 5 分钟，完成或断开后立即恢复原超时。
2. 模型先生视频收到 `bytes=N-` 时，单次最多返回 4 MiB，并给出准确的 `206`、`Content-Length` 和 `Content-Range`。浏览器到达分段尾部后按标准 Range 自动索取下一段；带明确结束位置的请求、后缀请求、HEAD 和 416 行为保持标准语义。
3. 新页面返回 `/media/model-mr/works/<id>/video` 和 `/media/model-mr/works/<id>/images/<ordinal>`。该路径不受 Caddy 的通用 API `no-store` 规则影响，应用返回 `private, max-age=3600`、`Vary: Cookie`、同源资源策略和禁止 MIME 猜测。
4. `/media/model-mr/*` 虽然不以 `/api/` 开头，服务端仍在任何文件查找前显式执行主人会话认证；未登录返回 401，绝不回退到公开静态页面。原 `/api/model-mr/.../video|images` 路由继续保留，避免旧页面或已打开标签立刻失效。
5. Service Worker 明确跳过 `/media/`，不把视频分段或私有原图写入离线 shell 缓存；Vite 本地预览把 `/media` 转发到同一后端。
6. 播放器增加 `waiting`、`stalled` 和 `playing` 状态说明。浏览器继续使用原生 Range 续传，不用脚本反复 `load()` 或强制跳转进度，避免 iOS 因丢失用户播放手势而制造新的暂停。

## 安全、兼容与数据边界

- 视频、图片、详情、评论和主人会话仍全部在 Git 外；本次不复制、转码、删除或改写任何业务媒体。
- 新媒体路径与旧 API 路径使用相同的路径白名单和媒体查找函数，不能通过路径参数访问任意文件。
- 私有缓存只允许浏览器自身保存一小时，不允许共享代理缓存；Service Worker 不持久化媒体。
- 本次只修复模型先生链路，不扩大普通博主、新闻、MCP、ASR、豆包或 AI 的权限和调用范围。
- `0.23.1` 已在所有者明确要求“正式发布”后通过既有受限发布器上线；媒体仍只允许主人会话读取。

## 验收

- 精确 Range、开放 Range 4 MiB 分段、完整 HEAD、Range HEAD、旧 API 兼容、私有缓存头与图片新路径均有合成媒体回归。
- 新 `/media/` 视频和图片在未登录状态均返回 401，不会落入公开 SPA。
- 独立 socket 回归证明媒体正文发送前把 30 秒临时提升到 300 秒，写完后恢复 30 秒。
- 即时 AI 207 项完整 Python 回归通过；前端 9 项源码契约、TypeScript/Vite 0.23.1 生产构建、静态产物一致及 npm 高危依赖审计通过。
- 正式发布后公网健康与 Service Worker 均为 0.23.1，即时 AI/Caddy active；未登录普通与 Range 私有媒体请求均为 401。iPhone 主人会话内的一次完整播放仍由所有者验收。

## 回滚

回滚应用代码即可恢复旧 URL 和旧传输行为；没有数据库迁移、媒体重写或资料转换。旧 API 路由始终保留，因此回滚期间已打开的旧页面不会因接口删除而失效。
