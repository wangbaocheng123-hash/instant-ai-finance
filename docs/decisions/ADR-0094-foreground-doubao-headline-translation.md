# ADR-0094：前台可见英文标题按需使用豆包翻译

- 日期：2026-11-23。
- 状态：IMPLEMENTED / ISOLATED_TESTED / RELEASED / FIELD_PENDING，0.35.0已上线，首次真实前台调用待验。
- 授权：所有者明确允许使用豆包API，要求打开即时AI时才翻译英文标题，不打开不翻译，密钥不得对外披露。

## 决定

标题改用所有者截图选定的`doubao-seed-translation-250915`，经固定方舟Responses地址请求，单次仅输入一个公开英文标题以及en→zh翻译选项。不把正文、摘要、URL、新闻ID、账号资料或业务库发给模型；不增加采集/翻译定时器、后台模型任务或历史补译。

密钥只在服务端环境读取，优先独立`INSTANT_AI_HEADLINE_ARK_API_KEY`，否则复用既有`INSTANT_AI_DOUBAO_ARK_API_KEY`。复用凭据不改变既有视频关键词模型。截图中的密钥不猜写进源码、前端、日志或报告；不新增注册、账户管理或密钥填写网页。本轮只核实systemd已挂载原文本密钥配置路径，没有读取其内容或另写生产凭据。

前端使用IntersectionObserver读取实际可见标题，且要求页面visible、主人已进入内容页、汉化开启。一次只提交一个标题；滚动或切换频道后只继续处理当时可见内容，详情也走同一调度器。隐藏页、pagehide、退出登录或关闭汉化后停止后续提交，已被服务器接受的一条可能完成并缓存，不能承诺撤销已发生的计费。结果在原DOM节点更新，避免逐标题重建列表或打断阅读。

`/api/translate`沿用主人登录及同源写保护，新增`visible_only=true`协议标记并限制每次最多一个条目；旧客户端无标记时拒绝，避免旧版后台轮询触发新付费提供器。该标记不是服务端对手机可见状态的独立证明，真实可见性由客户端检查；不把它当成新的身份或权限层。

复用现有SQLite译文/用量账本和全局锁。同标题在当前短期库内可跨新闻条目复用，并给新条目保存缓存副本；原题变更则失效。保留既有有效译文，不批量改用新模型重译；缓存仍随原新闻生命周期淘汰。软件每日50,000源字符上限只限制请求量，不代表方舟免费额度、Token余额或费用承诺。

响应须完整完成并含有效中文，否则保留英文，页面会话内不自动重试不明结果；手动重新开启汉化才重新允许尝试。请求有时间/大小上限，不跟随重定向，不透传提供器错误体或凭据。英文原题始终保留。

正文浏览器翻译和手动“中文摘要（备用）”的既有免费提供器保持，不把付费标题适配器扩散到正文/摘要。无数据库schema、数据位置或许可证变更。
