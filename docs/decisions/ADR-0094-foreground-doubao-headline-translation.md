# ADR-0094：前台可见英文标题按需使用豆包翻译

- 日期：2026-11-23。
- 状态：IMPLEMENTED / ISOLATED_TESTED / RELEASED / FIELD_PENDING，0.35.0及韩语扩展0.35.1已上线，首次真实前台调用待验。
- 授权：所有者明确允许使用豆包API，要求打开即时AI时才翻译英文标题，不打开不翻译，密钥不得对外披露。

## 决定

标题改用所有者截图选定的`doubao-seed-translation-250915`，经固定方舟Responses地址请求，单次仅输入一个公开英文标题以及en→zh翻译选项。不把正文、摘要、URL、新闻ID、账号资料或业务库发给模型；不增加采集/翻译定时器、后台模型任务或历史补译。

密钥只在服务端环境读取，优先独立`INSTANT_AI_HEADLINE_ARK_API_KEY`，否则复用既有`INSTANT_AI_DOUBAO_ARK_API_KEY`。复用凭据不改变既有视频关键词模型。截图中的密钥不猜写进源码、前端、日志或报告；不新增注册、账户管理或密钥填写网页。本轮只核实systemd已挂载原文本密钥配置路径，没有读取其内容或另写生产凭据。

前端使用IntersectionObserver读取实际可见标题，且要求页面visible、主人已进入内容页、汉化开启。一次只提交一个标题；滚动或切换频道后只继续处理当时可见内容，详情也走同一调度器。隐藏页、pagehide、退出登录或关闭汉化后停止后续提交，已被服务器接受的一条可能完成并缓存，不能承诺撤销已发生的计费。结果在原DOM节点更新，避免逐标题重建列表或打断阅读。

`/api/translate`沿用主人登录及同源写保护，新增`visible_only=true`协议标记并限制每次最多一个条目；旧客户端无标记时拒绝，避免旧版后台轮询触发新付费提供器。该标记不是服务端对手机可见状态的独立证明，真实可见性由客户端检查；不把它当成新的身份或权限层。

复用现有SQLite译文/用量账本和全局锁。同标题在当前短期库内可跨新闻条目复用，并给新条目保存缓存副本；原题变更则失效。保留既有有效译文，不批量改用新模型重译；缓存仍随原新闻生命周期淘汰。软件每日50,000源字符上限只限制请求量，不代表方舟免费额度、Token余额或费用承诺。

响应须完整完成并含有效中文，否则保留英文，页面会话内不自动重试不明结果；手动重新开启汉化才重新允许尝试。请求有时间/大小上限，不跟随重定向，不透传提供器错误体或凭据。英文原题始终保留。

正文浏览器翻译和手动“中文摘要（备用）”的既有免费提供器保持，不把付费标题适配器扩散到正文/摘要。无数据库schema、数据位置或许可证变更。

## 关系与回滚

替代ADR-0006的默认标题提供器及跨频道预先请求策略，继续复用缓存和原题保留。ADR-0014/0015的正文浏览器入口保持。代码回退不删除原新闻、已存译文、语音/关键词配置或其他资料；恢复旧客户端时须同步处理新协议拒绝旧请求的兼容边界。

## 0.35.1韩语扩展（已发布，真实前台使用待验）

所有者追加要求“韩语也翻译”。沿用同一模型、凭据、接口、缓存及前台调度；新增韩文字形识别，纯韩文、含英文缩写或汉字的韩文标题选择ko→zh，英文继续en→zh，中文与纯数字不提交。包含分解形式韩文字母的标题同样可识别；原始标题逐字保留，不为语言判断改写来源。

前后端使用相同的韩文字形范围，服务端needs_translation复用实际请求的source_language判断，避免前端认为可译而后台跳过。标题下方、详情和热点提示统一使用“原文标题”，避免将韩文误标为英文。既有输入长度、逐条/去重、缓存、失败不自动重试及后台停止后续的边界保持；不清空旧缓存或批量重译。

官方[Seed翻译模型语种表](https://docs.volcengine.com/docs/intelligent-processing/translate-image-text?lang=zh)列出ko（韩语）；本次只复用该语种标识，实际仍调用原Responses文本接口，没有使用图片处理API、上传图片或添加依赖。实际韩译结果及权限不以隔离夹具替代，正式发布与线上复核见下；真实前台使用仍待验，检查结果见STATUS/TASKS及实现报告。

## 0.35.2加载覆盖修复（开发候选，未发布）

所有者实际反馈切换开关才显示中文。0.35.1合成浏览器复现了旧新闻GET快照晚于已完成翻译而覆盖当前对象及DOM、attempted令同题不再处理的情况；同时失败队列中断原先仍显示开启。原正式请求日志没有当次轨迹，不能把合成复现说成实际接口失败或网络耗时证据。

候选在当前页面保留最多512条已完成译文，按完整原题匹配，在列表/热点刷新及详情加载时只补缺失译文，服务端已有有效结果优先，原题更改不沿用旧结果；退出登录清理。这是现有阅读器的有界临时状态，不新增持久/外部记忆服务或改变短期数据生命周期。新闻就绪即先渲染观察，其他模块继续原加载逻辑。

中断显示“汉化待重试”和“重试汉化”，未配置显示“汉化未就绪”；只有主人明确点击才重新允许处理未确认标题，已有译文继续复用，前台/单请求/隐藏后停止后续及不自动重试的费用边界保持。无接口、schema、许可证、依赖或凭据变更。
