# ADR-0022：模型先生单主人手机资料库与 Git 外媒体

- 状态：已采纳，局部取代 ADR-0021
- 日期：2026-08-30
- 决策者：产品所有者

## 背景

ADR-0021 把模型先生限制为作品和投资思路的精简只读索引，排除了视频、正式原文和评论。实际验收表明这无法满足所有者的使用方式：点击“视频原文”没有内容，“查看原作品”只会跳到抖音，和电脑端模型先生作品库差异过大。

所有者现明确要求：即时 AI 内的模型先生保留手机布局，但应能播放本地备份视频，查看和保存视频原文，使用已有豆包/本地识别结果，并查看作品评论；已生成的 388 个 360p H.264 + AAC 视频需要同步到云端。

## 决策

1. 模型先生仍是即时 AI 内的独立模块，不合并原工程的数据库、进程、管理后台或依赖。
2. 建立 `single-owner-mobile-library` 导出格式：索引、每作品详情和媒体目录都位于 Git 之外。索引只包含作品展示字段和媒体相对路径；详情只包含正式原文、白名单转写字段、评论作者/正文/时间/点赞/回复关系和投资思路。
3. 允许把 360p 有声压缩视频作为单主人运行数据同步到 `/var/lib/instant-ai/model-mr/media`。视频不进入 Git，不提供公开目录列表，所有详情、原文、评论和视频请求都必须先通过即时 AI 主人登录。
4. 视频接口支持 HTTP Range，便于 iPhone 按需播放和拖动；页面不自动播放，避免进入模型先生页面即消耗大量流量。抖音原地址只作为次要核验入口。
5. 本机即时 AI 回环连接模型先生服务时，普通视频识别、豆包识别和正式原文保存继续调用原服务。云端没有语音凭据时，按钮读取已经同步的正式/豆包结果并明确标记为缓存结果；程序同时提供独立的豆包录音文件识别 2.0 适配器，只有所有者另行批准并在服务器 Git 外 root 专用环境文件配置语音凭据后才启用，点击前必须再次提示按时长计费。不得上传模型先生整份 `.env`，不得把凭据写入 Git、页面、日志或公开接口。
6. 评论仅用于主人查看；不接入粉丝社区、头像、主页链接、评论图片、导入、删除、批量同步或管理工具。
7. 继续禁止把 `.env`、API 密钥、原始 SQLite、粉丝资料、本机绝对路径、原始 JSON、浏览器资料、Cookie、日志和管理接口写入 Git 或公开返回。

## 数据与发布边界

- Git：只保存代码、测试、导出程序和部署说明。
- 本机运行数据：`H:\即时AI文件库\model-mr`；媒体源为 `H:\模型先生智能体\模型视频_360p_有声`。
- 云端运行数据：`/var/lib/instant-ai/model-mr`；由 `instantai` 服务账户读取，目录不得由 Web 服务器直接静态暴露。
- 代码发布沿用即时 AI 独立 Git 仓库和受限发布器；1.335GiB 媒体走独立增量同步，后续只传新增或变化文件。
- 可选豆包语音凭据只允许存在 `/etc/instant-ai/model-mr-secrets.env`，权限 `0600`、root 持有；是否配置不影响视频、已有原文和评论浏览。普通本地 Whisper/OCR 仍依赖电脑端大型运行组件，未获额外依赖安装批准前，云端只载入已有普通识别结果。

## 安全与回滚

- 退出登录或会话过期后，媒体、原文和评论接口同样返回 401。
- 若新资料库异常，可停止同步并恢复 ADR-0021 的版本 1 索引；新闻采集和时变罗盘不受影响。
- 媒体同步不得删除云端其他目录，也不得改动时变罗盘仓库、服务或发布器。
