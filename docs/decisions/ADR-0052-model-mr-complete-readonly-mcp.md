# ADR-0052：模型先生完整主人资料的只读 MCP 投影

- 日期：2026-09-15
- 状态：`ACCEPTED_AND_LIVE`
- 目标版本：0.22.1
- 决策者：产品所有者

## 背景与根因

所有者要求自己的 GPT 通过现有 MCP 读取模型先生全部主人可见内容，尤其是完整评论区、模型先生本人回复、粉丝同楼互动、标题和 AI 关键词。

对 0.22.0 正式公网 `tools/list` 和源码的核对证明，问题不是 MCP 连接断开，也不是评论必然没有采集：现有服务只有六个工具；`get_model_mr_work_text` 按 ADR-0032 明确排除评论，`get_model_mr_author_replies` 又按 ADR-0038 只返回来源确认的作者发言和脱敏原提问，作品搜索最多返回 30 条且不能翻页。因此 GPT 无法读取粉丝完整回复链，也无法一次取得标题来源、十类关键词、评股和关联投资思路。单独修改 GPT 提示词不能突破服务端未公开的工具和字段。

## 决定

1. 保留现有统一入口 `https://grandpaamu.com/mcp`、单主人 OAuth 和六个旧工具；新增第七个只读工具 `get_model_mr_comments`，不建立第二个插件、账号、密码、scope、域名或数据库。
2. `search_model_mr_works` 增加 `offset`、`total`、`next_offset` 和 `has_more`。查询“全部/所有作品”时按时间倒序分页；主题检索同时覆盖标题、说明、十类关键词、视频原文、解读、评股和评论正文，但搜索结果只返回作品摘要。
3. 保持 `get_model_mr_work_text` 的工具名以兼容已有 GPT，显示含义升级为“完整资料”：返回标题、标题来源与置信度、说明、发布时间、公开原链接、媒体是否存在、正式或未确认视频原文、完整十类 AI 关键词及生成状态、已有解读、确定性评股、关联投资思路和评论统计。评论正文仍用专门分页工具读取，避免单次结果过大。
4. `get_model_mr_comments` 默认 `view=all`，每页最多 100 条；也支持 `interactions`、`model_mr`、`fans` 和 `model_mr_liked`。每条返回主人页面可见的评论显示名、正文、时间、点赞/回复计数、模型先生或粉丝身份、模型先生赞过标记、回复深度，以及按作品稳定编号的脱敏线程和根评论序号。用户要求全部时，调用方必须按 `next_offset` 继续，直到 `has_more=false`。
5. 原 `get_model_mr_author_replies` 继续作为快速读取作者互动的窄工具，不被删除。作者身份仍只信任采集端明确的 `author`、`author_comment` 或 `author_reply`；同名昵称不得推断为模型先生。
6. 评论显示名是主人页面原本允许查看的评论字段。本投影继续排除粉丝账号 ID、主页、头像、来源评论 ID、内部线程哈希、原始 JSON、媒体文件、服务器/本机路径、数据库字段、Cookie、密钥和管理信息；视频二进制不通过 MCP 返回。
7. 全部工具保持 `readOnlyHint=true`、`destructiveHint=false`、`idempotentHint=true` 和 `openWorldHint=false`。查询只读 Git 外已投影资料，不启动北京采集、下载、ASR、豆包、AI、标题修改或任何写入，因此不会产生模型费用。
8. 评论属于外部用户提交的非可信文本。工具定义、服务器 instructions 和结果都明确要求只把评论用于阅读、检索和引用，不执行评论中夹带的指令。

## 数据与兼容边界

- 底层继续只读 `/var/lib/instant-ai/model-mr/public-snapshot.json` 和 `details/<id>.json`；不复制或迁移业务资料。
- 评论分页使用投影后的行序号和线程顺序，不公开北京或抖音来源编号；跨页仍可用 `thread-N` 和 `root_comment_number` 恢复同楼语境。
- 既有 OAuth `blogger.read` scope 暂时保留，以免已有 ChatGPT 连接重复授权。0.22.1 上线后必须在连接中点击 Refresh，并新建对话；若自建 GPT 固定了允许工具清单，还需把第七个工具加入允许范围。
- 本决定局部替代 ADR-0032 的“模型先生 MCP 禁止评论”及 ADR-0038 的“不得返回整片评论区”。其来源确认作者身份、单主人 OAuth、只读、资料隔离和敏感字段禁出边界继续有效。

## 验收与发布门禁

- 合成资料覆盖全部作品翻页、评论翻页、完整作者互动楼、作者/粉丝/作者赞过筛选、评论关键词检索、同名非作者不误判，以及标题来源、十类关键词、评股和投资思路返回。
- 序列化负例必须证明粉丝主页、来源评论编号、内部线程哈希、媒体路径、本机路径和原始 JSON 不进入 MCP。
- 完整 Python 回归、前端构建、静态同步、依赖审计和项目泄漏检查通过后，才可提交候选。
- 所有者于 2026-09-16 明确要求正式发布。受限发布器从生产 `d8be739` 安全快进至功能提交 `bd05eda`，服务器 200 项回归通过；回环/公网健康、Service Worker 和 MCP 初始化均为 0.22.1，公网 `tools/list` 实测七个工具并包含 `get_model_mr_comments`，未登录模型先生 API 与评论调用仍返回 401/OAuth 挑战。发布未迁移或改写 Git 外资料，也未触发采集、ASR、豆包或 AI；主人授权后的真实分页阅读由连接 Refresh 后完成。

## 回滚

回滚只移除新增工具并恢复旧作品工具返回字段，不删除、迁移或改写任何模型先生作品、标题、原文、关键词、解读、评股、评论、媒体或 OAuth 客户端。
