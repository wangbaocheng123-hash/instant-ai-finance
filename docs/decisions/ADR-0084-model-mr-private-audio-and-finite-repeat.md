# ADR-0084：模型先生私有音频、单曲循环与定时停止

- 日期：2026-11-10
- 状态：`IMPLEMENTED / CANDIDATE_NOT_RELEASED`
- 候选版本：即时 AI `0.30.0`
- 决策来源：所有者要求每条作品可听音频、手机锁屏继续播放、循环及定时关闭。

## 决定

1. 复用主人已保存的有声视频，首次点击才提取第一条音轨；AAC 优先直接封装为快启 M4A，其他音频转为 AAC 96k。原视频、原文、评论及学习标记均不改，不重新下载、识别、调用 AI 或收费服务。图文及暂无本地视频的作品明确显示音轨暂缺，不自行生成朗读。
2. 增加 `/media/model-mr/works/<id>/audio`，与视频相同，在查找媒体和生成缓存之前先核验主人会话。GET、HEAD、Range 沿用私有媒体传输和 4 MiB 开放区间上限；返回 `audio/mp4`、`private` 与 `Vary: Cookie`。Service Worker 继续跳过全部 `/media/`，不提供公开音频目录或新账户体系。
3. 派生音频保存在模型先生 Git 外资料根的 `audio-cache/`。原视频的规范路径、文件身份、大小、纳秒修改时间及缓存格式版本共同决定缓存键；高清替换或源文件变化会使用新键。缓存最多 512 MiB，单文件上限 128 MiB，30 天未使用的已知缓存文件按需淘汰；空间不足时淘汰最久未用项，不触碰原媒体、未知文件和链接。目录拒绝符号链接，文件以临时 0600 文件写完、校验后原子替换。
4. 仅一个提取进程同时运行，重复 HEAD/Range 请求复用同一结果。ffprobe/ffmpeg 仅允许本地 file/pipe 协议及 MOV/Matroska 容器，执行有超时、文件大小及音频时长校验；错误不返回工具 stderr、本机路径或凭据。复用已有 ffmpeg，不安装新的系统组件。
5. 前端只创建一个稳定的原生 `<audio>`，位于会刷新的作品区之外。点作品按钮同步设置源并调用 `play()`，保留 iOS 用户手势；不先等待另一个准备请求。列表刷新、详情切换、分页与模块隐藏不重建音频。默认 `loop=true`，直接使用原生单曲循环，不依赖 `ended` 回调启动下一轮。
6. 提供 15、30、60、90 分钟模式。后端把原音频重复封装为**具有有限播放时长**的 M4A，前端 `loop=false`，到媒体尾部自然结束。这里的定时明确为播放进度：暂停不计时，拖动或变速会影响剩余时间；换作品或模式从头播放并重新计时。界面清楚展示这一规则，不把它称作墙钟闹钟。模式不会关闭手机或应用。
7. Media Session 在支持的平台提供标题及锁屏播放、暂停、停止与定位动作。开始音频时暂停视频；页面内任一视频开始播放时暂停该音频并释放它的锁屏控制。手动“停止收听”撤下音源，不在重开页面后自动播放。

## 理由与证据

- [Apple HTML5 媒体指南](https://developer.apple.com/library/archive/documentation/AudioVideo/Conceptual/Using_HTML5_Audio_Video/Introduction/Introduction.html)说明浏览器原生 audio/video 与控制能力；[Media Session API 文档](https://developer.mozilla.org/en-US/docs/Web/API/Media_Session_API)说明操作系统媒体界面的元数据与操作入口。
- [浏览器后台计时说明](https://developer.mozilla.org/en-US/docs/Web/API/Window/setTimeout#timeouts_in_inactive_tabs)表明脚本回调可能延迟。[WebKit 173332](https://bugs.webkit.org/show_bug.cgi?id=173332)是已经修复、但曾出现锁屏时 `ended` 脚本不能继续排歌的历史案例，不把它当成当前 iOS 必然存在的缺陷。采用原生 loop 和有限媒体，减少对后台脚本调度的依赖。
- 现场已有 `/usr/bin/ffmpeg` 和 `ffprobe`；本机 `ffmpeg -h full` 核实 `stream_loop`、容器/协议白名单选项。生产 systemd 已允许写 `/var/lib/instant-ai`，不需扩大目录或 root 权限。
- 备选方案：只隐藏原视频、把每轮重播或定时结束全部交给 JavaScript、批量提取全库音频。分别增加视频后台兼容性、脚本唤醒和无谓磁盘成本，未采用。

## 验收与发布边界

- 8 项新增后端用例实际运行 ffmpeg：证明只有 AAC 音轨、moov 快启、源视频字节不变、缓存命中不再编码、并发只生成一次、源变化换键、非 AAC 转换、无音轨和失败清理、缓存淘汰、符号链接拒绝、未登录不准备及认证后 Range/HEAD。
- 四种正式时长均对合成 1 秒输入生成重复 M4A，并用 ffprobe 核验 900/1800/3600/5400 秒；没有靠压缩时间参数冒充实际文件时长。
- Chromium 手机/桌面布局检查原生循环、用户手势、持久节点、离线刷新、详情/主题切换、单一音频、模式选择、停止与失败提示；有限合成音频在禁用页面 JavaScript 后仍自然结束。这是浏览器合成媒体证据，不是 iPhone 锁屏验收。
- 完整298项Python（可选跨仓1项跳过）、66项音频断言、32项学习/抖音链接、38项视频刷新及16项前端契约通过；TypeScript/Vite生产构建、8项静态资源逐字节一致和版本一致通过。Linux替代收尾检查核对60个必需文件与本轮敏感路径；PowerShell/H盘检查无法在该主机运行，旧脚本所需的0.21.1及旧发布通道STATUS字面标记在本轮HEAD基线已缺失，未为旧断言伪造当前状态。
- 正式发布仍等所有者针对本功能明确要求。发布后从 iPhone 主屏“即时 AI”进入，逐项验收锁屏跨过一轮、锁屏暂停/继续、定时自然停止、返回页面进度和换视频互斥；系统强退网页、断网或系统终止进程不保证持续播放。

## 影响与回滚

沿用 ADR-0022/0054/0055 的主人私有媒体边界，仅新增可删除的派生缓存，无数据库迁移。回滚应用代码即可撤回入口；缓存可在受控维护时单独删除后重建，不影响原视频与任何正式资料。北京下载器、采集器、罗盘及社区均不需更新或重启。
