# ADR-0063：模型先生逐条已学与上次学习定位

- 日期：2026-10-11
- 状态：已采纳、已实现并正式发布
- 版本：0.28.0

## 范围与决定

所有者把此前较完整的学习模式建议收缩为两个功能：每条作品可标记“已学”；下次打开点击“回到上次学习”，直接定位最后一次标记的作品，再自行选择下一条。这里的“最新”是最近标记时间，不是作品发布时间。此明确要求替代 STATUS/TASKS 中此前仅提案的秒级续播、三种学习状态、排序和自动下一条范围。

1. 使用已有稳定作品 ID 绑定单主人已学状态；不按卡片位置、作品标题或当前页序号绑定。现有作品顺序保持不变，不因标记变更顺序。
2. 状态独立存放在现有模型先生运行目录的 `learning.sqlite3`，云端为 `/var/lib/instant-ai/model-mr/learning.sqlite3`，本机为快照文件所在目录。同一资料域，不是外部记忆服务；不进入 Git、财经短期新闻库、北京同步包或模型原文/评论文件。仅保存学习标记和变更版本，不保存报告、GPT 观点或播放秒数。
3. 只在主人明确点击后写入。取消最后标记时，定位回退到仍为已学的最近一条；取消全部则显示未标记。重复同状态请求不改变最后学习位置。数据库事务及版本检查防止两台设备以旧状态覆盖新标记。
4. 原始内容后续同步或修订不覆盖学习记录。记录随服务器持久保留，不依赖手机缓存；删除浏览器缓存不清除云端标记。不引入用户表、角色或设置中心。
5. 只扩展既有主人应用 API：读取状态、保存单条状态及按作品 ID 定位元数据分页。鉴权和同源写保护沿用现有服务，不向只读 MCP 增加写工具，不改变订阅、通知、采集、转写或交易行为。
6. 定位只读取索引元数据和目标附近一页，不读取全库视频、评论或原文；跳转为明确的用户导航，不自动播放。窗口外邻页仍可加载，能返回最新作品列表。未知或已移除作品明确报错，不猜测替代位置。
7. 勾选状态和后台刷新只更新独立按钮/提示，不能替换正在播放的视频或其祖先节点，延续 0.27.3 播放器保护。保存失败不伪装已保存，冲突读取最新状态后让主人重新选择。

## 备选方案与影响

- 仅用手机 localStorage：实现较小，但换手机或清理浏览器会丢失；不满足跨次、跨设备找回，未采用。
- 将标记写入作品同步 JSON：会与北京后续标题/原文/评论修订争用，且混淆来源内容与主人操作，未采用。
- 在现有模型先生目录中使用 Python 自带 SQLite：无需依赖或外部服务，事务可以保证最近标记与版本同时更新，采用。只新增一份独立运行数据；发布与代码回滚不覆盖或删除它。
- 全套播放进度与学习模式：超过主人最新要求，本轮明确不做；不以未来可能使用为由预留多用户或复杂状态。

新增 `model-mr-learning-browser.cjs`，390px手机/1280px桌面共20项通过：最后标记不等于最新发布、重开持久化、750条中的第630位置定位、锚定分页/插入、保存失败就地提示/重读、409不自动重放、迟到响应及挂载视频不被替换。顶部、目标及保存错误手机截图经查看，无横向溢出。原38项播放器回归和双模块正常速度65秒播放（20/40/60秒刷新）通过；最终只新增就地错误提示后又执行播放器回归。TypeScript/Vite 0.28.0构建、八项静态一致及npm 0漏洞通过。
