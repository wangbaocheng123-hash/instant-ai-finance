# ADR-0038：模型先生作者回复 MCP 与普通博主阅读能力对齐

- 日期：2026-09-06
- 状态：`DEVELOPMENT_VERIFIED_NOT_RELEASED`
- 版本候选：0.21.0
- 决策者：产品所有者

## 背景

正式生产 0.20.1 的统一云端 MCP 有五个只读工具。模型先生作品文字工具按 ADR-0032 明确排除了全部评论，因此 GPT 无法读取评论区中由采集源确认的模型先生本人回复。与此同时，普通博主详情虽已有视频、原文和评论，但作者身份呈现、评论排序、评股、关键词和解读尚未与模型先生对齐。所有者要求补齐作者本人回复的 GPT 调用，并要求普通博主除“投资思路”和“智能问答”外按模型先生现有功能完善。

## 决定

1. 在既有 `https://grandpaamu.com/mcp` 上增加第六个只读工具 `get_model_mr_author_replies`。它按 `model-mr-work:` 作品编号读取作者互动，不建立第二个插件、账号、scope、数据库或 MCP 服务。
2. ADR-0032 对普通作品文字工具“不得返回评论”的限制继续有效；本 ADR 只用独立窄投影局部替代其 blanket prohibition。新工具仅接受来源明确标记为 `author`、`author_comment` 或 `author_reply` 的发言，不按昵称、显示名或文本推断作者。
3. 为保留语境，每个结果可带对应根提问的正文、时间、点赞数和回复数，但不返回提问者名称、账号、主页、来源评论编号、线程键、媒体、路径、原始 JSON 或整片评论区。单次最多 100 个线程，每线程最多 30 条作者发言；工具只读、幂等、非破坏且不触发采集、识别、豆包、AI 或资料写入。
4. 普通博主详情增加与模型先生一致的五个作品页签：本地视频、视频原文、评论、AI 关键词、解读感悟。评论内增加作者互动、粉丝评论和评股三个视图；作者身份只信任北京传输字段 `is_creator=true`，根发言映射为 `author_comment`，楼中回复映射为 `author_reply`。作者使用红色标识，作者点赞保持独立标记。
5. 普通博主复用模型先生的纯前端线程与排序函数：保留根问题及同楼上下文；作者回复优先；正点赞前十与其余有效长回复分开；同楼先显示 6 条，展开后每批 30 条；作品页先显示 60 组。排序只帮助阅读，不代表观点正确。
6. 普通博主主人库采用原表无损加列，Git 外保存人工确认原文来源、十类关键词、解读感悟和确定性评股报告。旧标题、原文与转写不迁移覆盖。评股只显示由既有本地证券名称表预先生成并保存的报告；系统不按简称猜测、不调用行情或 AI。旧作品没有报告时明确显示“尚无已同步报告”，不能把空白解释成“没有股票”。
7. 普通博主增加与模型先生同边界的可选后台处理：默认关闭，只接收开启后新完成的普通博主传输，不扫描历史；已有原文或关键词不覆盖。语音和关键词阶段需主人费用确认，每日每模块最多 20 次调用、每条视频最多 20 分钟，失败不自动付费重试。文本配置恢复后，只允许主人再次确认费用的手动关键词任务从调用前 `configuration` 状态重新排队；`review` 和自动到达任务不会被重复请求自动恢复。模型先生、普通博主自动队列与普通博主手动识别共用一个进程锁，避免并发调用提供器。
8. 普通博主明确不增加“投资思路”和“智能问答”。两个资料域仍分别存储；本次不把普通博主评论或新增元数据暴露给 MCP，也不修改财经新闻、时变罗盘或生产业务资料。

## 影响与兼容

- 0.21.0 正式发布后，已有 ChatGPT 连接只需 Refresh 即可从五个工具发现为六个工具；已有有效 OAuth 授权继续兼容，不应再次输入主人密码。
- MCP 作者回复能力取决于来源是否写入明确作者 kind。没有来源标记的同名评论不会被返回；这属于防误认边界，不是遗漏。
- 普通博主旧主人数据库在首次保存新字段时原地加列，运行数据继续位于 `/var/lib/instant-ai/blogger-agent`，不进入 Git。
- 自动处理开关升级后仍为关闭状态。本候选不配置或读取真实凭据，不启动队列、不执行真实付费调用。

## 验收与回滚

- 合成资料证明作者工具保留原提问与作者回复，同时排除粉丝姓名、主页、来源编号、同名非作者和线程键；普通作品文字工具仍不返回评论。
- MCP 协议发现六个只读工具，未授权调用继续失败，原两个博主工具和原三个模型先生工具行为不变。
- 普通博主契约覆盖旧主人库无损升级、来源明确的作者映射、关键词并发版本、解读、评股清理、默认关闭的新到队列、去重和共用提供器锁。
- 163 项完整 Python、19 项作者/MCP/队列针对性、7 项前端契约和 6 项共享评论纯逻辑均通过；TypeScript/Vite 构建和 npm 高危阈值审计通过。正式发布仍须由所有者明确发出口令。
- 回滚应用代码不删除 Git 外新增列、原文、关键词、解读、评股或处理队列；先保持自动开关关闭，不重跑未知状态的付费任务。
