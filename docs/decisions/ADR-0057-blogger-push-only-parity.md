# ADR-0057：普通博主以北京单一采集源完成接收后能力对齐

- 日期：2026-09-24
- 状态：`ACCEPTED / IMPLEMENTED_LOCALLY / NOT_RELEASED`
- 目标版本：即时 AI `0.24.0`；北京博主采集器 `1.1.0`
- 决策者：产品所有者

## 背景

普通“博主采集”已经能把北京采集的作品签名推送到新加坡即时 AI，但显示、标题、
图文、移动视频、评论语境和 MCP 读取能力仍落后于模型先生。所有者要求普通博主
对齐模型先生已成熟的作品阅读能力，但明确排除“投资思路”和“智能问答”。

所有者随后纠正了数据方向：抖音、作品和评论的采集只在北京采集器执行；新加坡
即时 AI 只接收北京推送，不应每 3 分钟检查作品，也不应按发布后 24 小时内
15 分钟、之后 60 分钟的规则反向刷新评论。这些是北京模型先生下载器的采集
调度，不得复制到新加坡普通博主接收端。

## 决定

1. **北京是唯一采集源。** 北京负责发现作品、下载媒体、获取公开正文和评论，
   并以 `blogger-transfer/v1` 签名修订推送。新加坡只验签、校验 artifact、保存、
   投影、接收后处理、显示和提供只读 MCP。
2. **不建立反向轮询。** 新加坡执行器不扫描抖音、北京服务、传输账本或评论源。
   一条作品只在签名 `complete` 回调已验证媒体后成为新到达；评论只随北京后续
   推送的新修订变化。手机每四秒读取的只是新加坡本地处理任务状态，不是采集或刷评。
3. **接收后处理只作内部补全。** 未来新推送的已验证视频可在现有每日 20 次、
   单条 20 分钟、串行锁和不明费用不自动重试的边界下补齐原文、标题与 AI 关键词。
   升级时不回扫历史作品；旧自动任务在边界不明时转为 `review`。主人暂停后保持暂停。
4. **标题优先级固定。** 人工标题 > 北京推送的有效原题 > 开头画面 OCR > 根据正式
   视频原文生成的 AI 标题 > 编号占位。只有北京原作品无有效标题时，关键词的
   同一次多模态请求才可读取最多四张开头临时帧并返回标题。画面只是标题证据，
   绝不写入视频原文；不把连续字幕 OCR 当作原文。
5. **作品形态对齐。** 北京普通博主解析支持 `/video/`、`/note/` 和 `/article/`；
   长图文保留公开 Markdown 正文和有序原图。图文在新加坡显示正文与私有原图库，
   不进入视频 ASR。后续普通博主新视频在北京保存为半尺寸 H.264/AAC、
   `yuv420p` 与 faststart，保留 240 像素最低宽度以平衡手机可读性和存储。
6. **移动媒体对齐。** 普通博主使用主人认证的 `/media/blogger/` 视频与图片地址。
   视频开放 `HEAD` 和最大 4 MiB 分段 Range，使用 300 秒私有媒体发送窗口，保留旧 API
   路由兼容；页面显示缓冲、停滞和续传提示。
7. **MCP 只读对齐。** 保留 `search_blogger_videos` 和 `get_blogger_video_text` 的兼容名称，
   扩充为作品分页、标题来源、作品类型、原文、十类关键词、已有解读、确定性评股
   和评论统计；新增全部评论分页与博主本人回复快捷工具。工具只读最后一次北京
   推送的快照，不触发采集、识别或 AI。粉丝账号 ID、来源评论 ID、内部线程键、
   路径、媒体、原始 JSON、Cookie 和密钥不对外返回；评论文本被标注为不可执行的外部资料。
8. **明确不对齐的功能。** 普通博主不新增投资思路、智能问答、模型先生三分钟
   作品检查、15/60 分钟评论刷新或新加坡主动补采。

## 替代与兼容

- 本 ADR 替代 ADR-0039 第 2 条的“新加坡每三秒扫描传输到达账本”；到达修复不再靠
  轮询，只由完成回调触发。ADR-0039 的主人单条补做、付费边界、任务去重与可观测状态
  继续有效。
- 本 ADR 替代 ADR-0038 第 8 条中“普通博主新增元数据不暴露给 MCP”的部分；
  现在可以通过同一主人 OAuth 读取经白名单清理的资料和评论。“不增加投资思路与
  智能问答”仍然有效。
- 旧 `cloud-video:` 编号、旧 MCP 工具名、旧视频 API 和旧主人库保持兼容；数据库只无损加列。

## 验收和发布门禁

- 合成回归必须证明新加坡执行器没有到达扫描方法，页面状态读取不创建轮询水位，
  只有明确的传输完成回调可入队。
- 必须覆盖图文不进入 ASR、占位标题共用一次关键词请求、标题并发优先级、私有媒体
  Range、全部评论/MCP 分页、`/article/` 正文与原图、北京时间以及半尺寸 iPhone 兼容编码。
- 本地候选已通过即时 AI 210 项 Python、北京采集器 229 项 Python、前端 10 项源码契约和
  TypeScript/Vite `0.24.0` 生产构建。正式发布前还必须运行两端固定发布门禁、敏感文件检查和
  实际服务健康验收；未收到本轮“正式发布”指令前不推送、不上线。

## 回滚

应用代码可回滚；无损新增的标题元数据列和 Git 外主人内容保留。回滚不删除北京已采集或
新加坡已验签的作品、图片、视频和评论修订；也不会启用任何新加坡反向采集。
