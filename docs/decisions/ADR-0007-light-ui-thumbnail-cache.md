# ADR-0007：白色新闻阅读界面与轻量缩略图缓存

- 状态：`ACCEPTED`
- 日期：2026-08-24
- 决策者：用户要求白底黑字，并把新闻改为左侧缩略图、右侧标题

## 背景

现有深色终端样式不符合用户的阅读偏好，纯文字列表也不利于快速区分新闻。用户希望客户端采用白色风格、黑色字体，并为新闻显示小型封面图；同时此前已经明确不要自动视频和大量流量。

## 决定

- 展示分叉改为白底、黑色正文、浅灰分隔和少量蓝/橙状态色，保留 12 个财经频道、滚动快讯、汉化、搜索和证据详情。
- 列表和搜索结果采用“左侧 82–90 px 缩略图、右侧标题与来源”；详情页显示一张较大的同源封面。
- 只读取 RSS/Atom/HTML 列表中明确提供的图片元数据，不为无图条目批量抓取新闻正文页面，也不恢复视频、直播或 iframe。
- 图片由本机 Python 服务按需下载，前端只访问同源 `/api/items/{id}/thumbnail`；CSP 继续禁止外部图片直连、媒体和 frame。
- 单张远程图片最多 1,250,000 字节，同时下载最多 3 张，只接受 JPEG、PNG、WebP 和 AVIF；私网、回环、保留地址、凭据 URL 和非 80/443 端口均拒绝。
- 成功图片写入 `H:\即时AI文件库\cache\thumbnails`；SQLite schema 升至 4，以 `item_thumbnails` 保存候选 URL、缓存位置、类型、大小和状态。
- 无来源图片、下载失败或超过限制时，本机按 AI、黄金、矿业、宏观、亚洲等主题生成小型 SVG 封面；因此每条新闻都有稳定视觉入口，但不会为占位图产生网络流量。
- `<img loading="lazy">` 延迟加载列表图片；真实图片缓存 7 天浏览器缓存，无图主题封面缓存 5 分钟。

## 理由

该方案满足白色阅读与左图右文的视觉目标，同时把额外流量限制在用户实际看到的、来源明确提供的图片。H 盘缓存避免重复下载；本机主题封面确保 Google News 等不提供图片的发现源也有一致版式。

## 影响

- 来源图片可能受原网站条款和版权约束；当前仅供本机所有者作为新闻链接预览，不把图片当授权素材库或对外分发。
- `cache/thumbnails` 是可删除缓存；删除后真实图片会在再次查看时按规则重新获取，正式新闻和证据不受影响。
- 某些来源没有图片或图片被安全/大小规则拒绝，界面会显示主题封面，而不是假装存在新闻原图。
- 当前不安装 Pillow 等图像处理依赖；若以后需要统一压缩/裁剪质量，必须另行评估依赖和迁移成本。

## 证据

- 图片提取与安全缓存：`product/instant_ai/collectors.py`、`product/instant_ai/thumbnails.py`
- 本机图片接口：`product/instant_ai/server.py`
- 展示分叉提交：`a4b5b11b7bde888c51c958e807a54d5ad7a3f20e`
- 本地验收：历史 Feed 恢复 42 个真实图片候选；真实 WebP 27,916 字节与 774 字节主题 SVG 均通过接口和浏览器验证。

## 关系

本 ADR 补充 ADR-0005 的展示层和 ADR-0006 的中英标题能力，不改变 localhost、H 盘、单机单用户、无账户和无自动交易边界。
