# ADR-0088：模型先生音频接续、逐分钟定时与固定录音播报

- 日期：2026-11-15
- 状态：`IMPLEMENTED / NOT_RELEASED / IPHONE_ACCEPTANCE_PENDING`
- 候选版本：即时 AI `0.32.0`；正式版本仍为`0.31.0`。
- 来源：所有者反馈第129条播放中勾选下一条时衔接被打断，要求点哪条从哪条开头、1～30分钟逐分钟定时及1小时；又明确要求用固定数字/年月日录音改善播报颤音。
- 本决定按最新指令替代ADR-0087中“给当前条补报”和“调整模式重播/重计时”的相关行为；保留单主人认证、Git外缓存与原资料边界。

## 播放行为

1. 直接点某条“播放音频”永远选择该条并从原声开头开始，同时开始本次收听的定时。缺失或损坏的所选音轨必须明确失败，不能悄悄改播较新作品。自动连播中的后续不可用作品仍可跳过。
2. 勾选/取消自动下一条或修改定时期间，当前解码器继续播放。后台准备独立且静音的接续元素，在同一原声位置就绪后交接；保留暂停、音量、静音与倍速。准备期间主要为暂停预加载，不要求手机同时持续播放两个媒体；原生路径在点击中发出播放授权请求后立即暂停，真正交接等媒体可播及定位完成。任何时候只让一段声音可听，准备失败保留原播放和原设置。
3. 进入连播时第一条只包含当前原声，不插入当前条的日期播报；到下一条前才播该条日期、序号，再播原声。服务端按原声位置截取首条，前端交接时还计入准备期间已经听过的进度，避免回到点击勾选时的旧位置。准备期间原作品已循环或跨条时，按实际当前作品重新准备，最多重试两次。
4. 定时选项为“不定时”、1至30每个整数分钟、1小时；不提供31～59及90分钟。按播放进度跨自动切换累计，暂停不计时，变速/拖动仍按媒体进度影响剩余值。重新选择时长从该次设置计起；单独切换连播保留剩余秒数，包括上一项设置尚未准备完成的情况。
5. 有限停止点仍在媒体中。单曲定时只重复所选作品，不插播提示或其他作品；连播定时共享一个剩余预算，包含下条提示，到时自然结束。取消定时或连播保持原声当前位置；已经结束/暂停的音频不会因设置变化自动恢复。视频开始时取消未完成交接、回显实际设置并暂停音频，停止收听清理两侧资源及晚到请求。

## 固定录音

- 明确使用固定数字、年月日、序数及“条”的录音组合，不为正常日期逐次运行通用TTS。复用`rts-cn/zh`提交`bd238bccc671c784e0daed880d558d258a676e1a`的`cn/link`词库，MPL-2.0；53个原文件的SHA-256、精确路径和固定URL保存在`product/instant_ai/announcement_prompts.json`。
- 原文件只读下载后，在Git外模型资料根`audio-tools/recorded-cnlink-bd238bcc-v1`保存约1MiB派生PCM及来源/许可证/README。ffmpeg只做一次格式解码（来源含A-law）、16kHz单声道、固定音量和短淡入淡出，随后直接离线拼接。音质改善来自固定录音，升采样不等于增加原始录音带宽；不承诺真人录音棚音质。
- “条”使用上游`directory/8000/dir-result_match.wav`首个词0～0.42秒，对应录音脚本“条相应的结果”；保留完整音节及其后静音，截去后面的词。日期组与序号之间留短停顿。万位以上编号按数字逐位读，避免把缺少的“万”录音读成“百万”。
- 完整README和MPL许可证随运行词库保留，SOURCE说明解码、定幅、修边和上述摘取。代码、清单和许可证入Git，音频原件、派生PCM、试听及截图均不入Git。来源、提交、源码/字幕证据和运行验证见`research/MODEL_MR_RECORDED_PROMPTS_REUSE.md`。
- 固定词库无有效日期时返回未匹配，继续使用原离线组件明确读“发布日期未知”，不捏造历史日期。词库下载、哈希或合成失败必须报错，不静默恢复含糊报读；首条原声准备不依赖日期词库。缓存键包含新播报版本，旧颤音派生段不再复用。

## 权限与资源

原GET/HEAD/Range与主人认证先后顺序保持。清单增加`next`、`intro`及`seconds`参数，校验为布尔标记及不大于所选分钟数的有限剩余秒数；没有新增持久写接口或外部记忆服务。会话、HLS分段和两类音频缓存仍受ADR-0087限制。固定词库只有约1MiB，首次最多4个下载/解码并行任务、单源128KiB限制、45秒总准备预算加正在进行的解码超时；拒绝越界路径/链接，临时目录原子替换，后续无网络复用。不安装全局环境、大模型、系统服务或额外付费TTS。

- 完整317项Python通过（可选跨仓1项跳过）。新增用例验证固定词顺序/序号、哈希/私有缓存/离线复用、坏素材及路径拒绝、输出静音/幅度和重复合成一致；另验证所选条损坏不能跳条、首条不补播报、单曲有限重复及跨作品剩余预算。
