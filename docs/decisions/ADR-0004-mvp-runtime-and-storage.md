# ADR-0004：即时 AI MVP 采用 Python 本地核心、SQLite 与 Edge 应用壳

- 状态：`ACCEPTED`
- 日期：2026-08-23
- 决策者：用户明确要求“接着开发，继续开发，不要停”

## 决定

1. D0 批准 R0 推荐的“薄型自有领域核心 + 可选 sidecar”方向，先实现不依赖 sidecar 也能运行的核心闭环。
2. MVP 核心使用本机已有 Python，HTTP 服务只监听 `127.0.0.1`；第一版不安装 Docker、WSL、Electron 或全局依赖。
3. 正式数据库使用 SQLite WAL，路径固定为 `H:\即时AI文件库\database\instant_ai.db`；原始响应按 SHA-256 存入 H 盘 `raw`。
4. 桌面窗口使用本机 Edge 的 `--app` 模式，桌面快捷方式名称固定为 `即时 AI`。这是第一版壳，未来可在不改变领域/存储契约的前提下替换为打包壳。
5. 第一批实现 RSS/Atom 与官方网页链接采集、证据保存、跨次幂等、主题/实体/事件规则、重要度、全文查询、收藏、来源状态和 CSV 导出。
6. 永久保持单机单用户、无注册登录、无姓名邮箱、无团队权限层；GitHub SSH 只用于研发上游，不属于产品运行依赖。
7. schema 2 增加可审计 AI 任务和低噪声通知 outbox；没有安全模型配置时 AI 任务停在等待状态，任何规则文本不得冒充模型输出。
8. 数据库备份必须带 SHA-256 校验，并支持在 H 盘隔离恢复、完整性检查、计数核验、临时库清理和审计报告留存。

## 理由

该组合能在当前 Windows 环境立即交付桌面可用版本，依赖和磁盘成本最低，同时保留未来接入 RSSHub、changedetection、OpenBB 与 AI 模型的清晰边界。

## 后果

- 首版依赖本机 Python 与 Edge；完成核心闭环后再评估独立 EXE 打包。
- SQLite/FTS5 足以支持个人库起步；所有迁移必须版本化并可备份恢复。
- Edge 窗口关闭后本地服务仍可保持运行；重复点击快捷方式只打开同一 localhost 应用。
