# ADR-0072：榫卯社区改为顶部导航、中央交流大屏与底部输入栏

- 状态：`ACCEPTED / READY_FOR_RELEASE`
- 日期：2026-10-15
- 决策者：产品所有者

## 背景

社区0.2.0—0.3.5候选把“尺寸型 / 交流区 / 榫卯108道”固定在底部，并在交流区中间使用左侧发表表单、右侧消息列表的双栏布局。所有者明确要求三项导航移到顶部，底部改成类似聊天窗口的打字区域，中间大屏主要显示大家发表的意见、问题和咨询内容。

## 决定

1. 三项社区入口继续保持“尺寸型 / 交流区 / 榫卯108道”的顺序和原有视图，但导航移到站点页头下方并在滚动时保持可见。
2. 交流区中央只保留公开交流大屏，集中显示问题、咨询、经验与意见；不再把发表表单作为左侧主内容占用大屏空间。
3. 称呼、纯文字内容和发送按钮组成固定在窗口底部的紧凑输入栏。输入栏只在交流区显示；切换到尺寸型或榫卯108道时自动隐藏。
4. 手机窄屏仍保持三项顶部导航、中央单列消息和底部输入栏，输入栏预留安全区，不遮挡最后一段内容。
5. 此次只改变公开页面布局和文字，不改变`GET/POST /api/messages`、20/500字限制、15秒/每小时限流、90天/5000条保留、纯文字安全渲染或匿名统计。

## 理由与影响

该结构把浏览、阅读和发表按空间分层：入口在顶部，交流内容占据中央主要视野，发言动作始终靠近底部键盘区域，更接近所有者所描述的聊天大厅。尺寸型和108道仍是独立内容视图，不会被固定输入栏覆盖。

## 证据

- 社区27项测试通过，新增顶部导航位于`main`之前、旧底部导航移除、交流大屏先于输入栏、输入栏按视图显隐等契约。
- 首页与后台JavaScript语法检查通过；0.3.6本地完整服务返回目标结构，实际临时数据库发言及列表回读成功。
- 当前只在`main`形成0.3.6候选，未推进`sunmao-production`或操作北京生产进程。

## 替代与撤销

本决定替代ADR-0066第1项中的“底部导航”位置和原双栏交流页布局；三项入口、默认交流区、公开纯文字边界、独立SQLite与安全限制继续有效。回滚只需回退公开页面资源，不迁移或删除消息数据。
