# ADR-0093：北京视频转换预算、短期源缓存与明确阶段错误

- 日期：2026-11-22。
- 状态：IMPLEMENTED / TESTED / MAIN_CANDIDATE；1.3.1尚未发布。
- 依据：所有者真实单链接7710805388309244411在转换阶段触发600秒硬超时，旧清理逻辑删掉已下载输入，页面只提示查看脱敏诊断；事实与验证见research/BLOGGER_TRANSCODE_TIMEOUT_20261122.md。

## 决定

继续复用FFmpeg和原下载/入库/签名发送链，使用veryfast与受限线程；半尺寸、H264/AAC和原手机兼容格式保持。由ffprobe读取本地时长后制定600～3600秒预算，时长未知用1800秒；不把调大时限当作目标真实视频已成功，也不无限等待。

已下载且有轨道的输入保留24小时有效校验缓存，记录只含作品ID/时间/大小/摘要，严禁保存Cookie、请求头、带签名媒体URL、解析原始JSON或凭据。临时原片与音频留在既有Git外北京媒体目录，不登记asset、不推送新加坡、不作为长期档案；成功后删除，后续采集清理过期缓存，不增加定时器。重试必须匹配ID和摘要；不跟随或覆盖符号链接，不把不完整输出安装成最终作品。

已知转换错误以安全码和人能理解的阶段提示展示，原始ffmpeg命令/路径不透传页面。采集成功、发送成功、原文识别仍分开。无新加坡反向采集、AI或报告接口，单主人、数据隔离及原审批保持。

## 验收与发布

261项完整检查无跳过通过，包括缓存续作、音轨复用、身份/摘要/过期/路径保护、失败不成片和安全提示；实际FFmpeg半尺寸手机格式验证通过。没有真实重抓本条或改变生产，1.3.1仍需按北京发布规则取得明确确认后上线并单条现场验证。

回滚代码不会删除已完成视频或已送达回执；临时输入不暴露到静态站点。若回滚旧版本，其原清理行为可能删除缓存，所以不能承诺旧版继续复用新缓存。
