# ADR-0074：榫卯社区尺寸型使用白名单外链资料清单

- 状态：`ACCEPTED / READY_FOR_RELEASE`
- 日期：2026-10-15
- 决策者：产品所有者
- 目标版本：榫卯 AI 社区 `0.3.7`

## 背景

尺寸型此前只有器物尺寸、结构尺寸和图纸连接三个占位。所有者提供第一条微信文章，并说明后续还会继续提供链接，希望先查看第一条的展示效果。当前服务器访问该公开文章时触发微信“环境异常”验证，无法可靠取得原标题、作者和封面；不得因此猜测文章内容或绕过平台验证。

## 决定

1. 尺寸资料保存为Git内静态`web/size-resources.json`顺序清单；每条包含稳定ID、序号、显示标题、来源、简短说明和原始URL，后续链接按序追加。
2. 第一条使用所有者给出的精确URL，并以“尺寸资料 · 微信文章 01”作为不冒充原文的通用标题。取得可靠标题或所有者提供展示文字后，可只更新卡片元数据。
3. 当前白名单只接受无账号、无端口、无查询串、无片段的`https://mp.weixin.qq.com/s/<文章ID>`。外链固定新窗口、`noopener noreferrer`和`no-referrer`。
4. 前端只用DOM节点和`textContent`渲染清单，不接受HTML、脚本、图片或iframe；加载失败明确提示，不影响交流区和榫卯108道。
5. 页面显示真实资料数量，桌面使用自适应卡片网格，手机改为单列。资料仍留在原平台，社区只保存链接和最小展示元数据。

## 证据

- 精确URL、HTTPS主机、路径、无查询串及序号契约测试通过；页面加载、白名单、纯文本渲染、安全新窗口和手机单列契约通过。
- 完整30项社区测试、首页与后台JavaScript语法、Python编译通过。
- 本地完整服务返回0.3.7，`/size-resources.json`返回HTTP 200、`application/json`和第一条精确链接。

## 发布边界

本决定当前只形成`main`候选。普通修改不推进`sunmao-production`；只有所有者明确要求发布榫卯AI社区后，才由社区专用发布器上线。发布不得重启采集器或模型下载器。
