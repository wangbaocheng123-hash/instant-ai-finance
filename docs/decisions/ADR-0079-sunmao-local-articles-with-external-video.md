# ADR-0079：授权文章站内阅读与视频外链

- 状态：已采纳，0.3.10候选已实现，生产发布另行授权。
- 日期：2026-10-16。
- 关系：扩展ADR-0076/0077/0078，不改变独立社区部署、统一资料表或Git外数据位置。

## 背景

所有者要求把4条重新提供的本人微信资料正文和图片搬入尺寸栏目，保留原七代鲁班凳卡片，并把文内视频入口放回对应文章。公开页面本次可读取，含24张图片和3条视频入口；现有前端只有外链与图集，不能表达文字、图片、视频交错顺序。

## 备选项与决定

- 只加链接：不能满足站内看正文与图片。
- 搬运HTML或嵌入微信iframe：带入脚本、验证依赖及不必要的外站加载，不采用。
- **采用白名单正文块**：复用`knowledge_items.body`保存纯JSON块，新增`local_article`类型，支持文字、标题、图片位置和外部视频链接；不扩展数据库表结构。前端原生details展开，DOM纯文本渲染，同源资源图，不嵌入播放器。

## 导入与安全

- 只处理明确授权的阿木爷爷文章，保留真实标题、来源与作者，授权字段固定为`owner_authorized_copy`。不猜尺寸或补写视频内容。
- 图片和资料包在Git外，原始网页及令牌不上传。导入器无网络能力，调用者先核实来源并准备受控包；文件路径必须位于包内，SHA-256必须一致。
- 每篇事务写入，最多40图/100MiB、每图20MiB、300正文块、10万字。随机资源ID和受限文件权限沿用既有存储；精确微信来源与视频URL白名单，禁止任意HTML/iframe。
- 采用插入限定与相同内容幂等重试，不覆盖既有文章、顺序或来源。不同内容修订需要后续明确版本流程；本次失败仅删除自身新建资源并回滚该篇数据库。批次中已成功文章保持不变。
- 私有或撤回资源不再通过接口公开；浏览器已有长期缓存不承诺立即回收。完整主人录入后台、统一检索与成套离盘备份仍为后续任务。

## 发布和证据

代码与资料分离：main推送不代表北京已导入，生产代码发布也不代表资料已入库。正式操作需先备份，再经受控CLI导入，最后核对英文公网精确版本、文章数量和每张资源摘要；不触碰采集器、下载器或DNS/Caddy。

45项Python回归通过，其中12项覆盖文章顺序、幂等、冲突拒绝、URL/类型/路径/SHA校验、私有/撤回、失败回滚和真实HTTP资源读取。隔离Chromium在390×844及1280×900验证5卡、4篇文章、24张图片加载、3个视频外链、零iframe、无横向溢出和无脚本执行；交流输入仍16px且无昵称。此验证不代替微信播放或真实iPhone软键盘验收。
