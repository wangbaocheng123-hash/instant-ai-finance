# ADR-0075：榫卯社区手机输入框取消昵称并避免聚焦放大

- 状态：`ACCEPTED / MAIN READY / NOT YET RELEASED`
- 日期：2026-10-16
- 决策者：产品所有者
- 目标版本：榫卯 AI 社区 `0.3.8`

## 背景

0.3.7手机交流栏把昵称和正文都放在固定底栏，窄屏又把输入字号降到13px。iPhone等移动浏览器聚焦小于16px的表单控件时会自动放大并平移页面，表现为正文输入框突然跳到屏幕中间、整页被放大。所有者同时明确“你的昵称”不需要出现，也不需要访客设置。

## 决定

1. 公开发表栏只保留正文和发送按钮，昵称输入、昵称计数及对应前端校验全部移除。正文仍为纯文字1—500字。
2. 新页面只提交`{"body": ...}`。服务器继续临时兼容旧缓存页面的`{"nickname": ..., "body": ...}`，但忽略旧昵称并统一以内部占位称呼“木友”保存；不修改或删除历史留言的原称呼，也不迁移现有SQLite列。
3. 所有公共交流输入控件的计算字号至少为16px，并固定`text-size-adjust: 100%`。手机断点取消页面平滑滚动，降低聚焦时额外位移；不得用`maximum-scale=1`或`user-scalable=no`禁止用户缩放。
4. 同源限制、15秒/每小时10条限流、90天/5000条保留、纯文字`textContent`渲染、匿名访问统计和独立服务边界均不变。

## 验收

- 完整30项社区测试、首页与后台JavaScript语法检查、Python编译通过。
- 390×844移动视口实际加载并聚焦正文框：输入字号16px，`innerWidth`和`scrollWidth`均为390，聚焦前后`scrollX=0`、`scrollY=0`，输入框坐标不变，昵称控件不存在；页面无横向溢出。
- 本地完整服务`/health/version`返回0.3.8。上述浏览器回归验证布局与计算样式，不冒充真实iPhone软键盘验收。

## 发布边界

普通修改只进入`main`。只有所有者使用仓库约定的社区发布短语后，才可推进`sunmao-production`并启动一次社区专用发布器；不得重启或修改北京博主采集器、模型下载器、即时AI、时变罗盘或MCP。
