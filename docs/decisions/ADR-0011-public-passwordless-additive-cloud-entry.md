# ADR-0011：无账户无密码的增量云端入口

- 状态：`SUPERSEDED_BY_ADR_0020`
- 日期：2026-08-28
- 决策者：用户明确要求“即时消息不用加账户、密码，什么都不用加”，并要求云端原有文件只保留、只增加

## 背景

ADR-0009 原计划在 Nginx 层增加单一访问口令。用户现在明确取消该访问层，并要求从 iPhone 主屏幕直接打开、立即加载和持续刷新。同时，既有阿里云实例中已经有其他资料与系统，部署不能覆盖、删除或重命名任何既有文件、站点、服务或数据。

## 决定

1. 即时 AI 继续不建立注册、登录、姓名、邮箱、密码、个人资料、角色或多用户账户。
2. 公网入口不使用 HTTP Basic Auth、访问口令或登录页。任何知道地址的人都可以读取公开财经消息，因此该入口不承诺私密性。
3. 云端只保存自行采集、可重建、会自动淘汰的公开财经信息；H 盘数据库、原文、日志、缓存、密钥和个人资料不得上传。
4. Python 仍只监听服务器回环地址 `127.0.0.1:18765`，公网只经过 HTTPS 反向代理；不得直接开放 18765。
5. 部署必须增量进行：先只读盘点现有目录、服务、端口、Nginx 站点和证书；程序使用独立目录 `/opt/instant-ai` 与 `/var/lib/instant-ai`；只新增同名空间内的服务和站点配置。遇到任何目标已存在或端口/域名冲突立即停止，不覆盖原件。
6. Web App 的 API 请求使用 `no-store`；Service Worker 不缓存 `/api/`；界面每 60 秒读取一次最新窗口，并在 iPhone 从后台恢复、重新联网或重新打开时立即刷新。后端每 5 分钟持续采集。

## 影响

- 添加到 iPhone 主屏幕后，无需输入任何账户或密码即可打开。
- 为满足 iOS Service Worker/PWA 的可靠运行，正式入口仍必须使用 HTTPS。
- 取消访问口令意味着链接可能被转发、扫描或被其他人访问；安全边界改为“只公开可公开的财经消息，不上传个人数据”。
- 本 ADR 替代 ADR-0009 中“服务器级访问口令”的要求；ADR-0009 的云端独立数据、HTTPS、回环监听和 H 盘不上云要求继续有效。

## 替代关系

用户于 2026-08-30 明确要求云端增加主人账户登录并保持 30 天会话，ADR-0020 因此替代本 ADR 的“公网无密码”决定。只新增部署、云端独立数据、HTTPS、回环监听、H 盘不上云和实时刷新要求继续有效。
