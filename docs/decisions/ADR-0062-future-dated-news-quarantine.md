# ADR-0062：伪未来新闻隔离与旧错日期清理

- 日期：2026-10-11
- 状态：`ACCEPTED / IMPLEMENTED / RELEASE AUTHORIZED`
- 目标版本：即时 AI `0.27.2`
- 决策者：产品所有者
- 关系：修正 ADR-0010 的短周期清理边界，补充 ADR-0061 的来源恢复；不改变新闻正文、通知、模型先生、北京采集或交易边界。

## 背景与证据

0.27.1上线后，所有者在12:09手机截图中确认“全球即时财经”顶部仍是“市政证券承销商共支付$325,000的罚款”，界面时间显示为`12/16 20:00`；第二条Arthur Levitt爱荷华州投资者会议显示为`11/05 20:00`。当天为2026-10-11，这两条以未来月日倒序压在列表顶部。

回看SEC原始页面确认，第一条是1997年12月16日的`97-114`新闻稿，第二条是1997年11月5日的`97-99`新闻稿，并非2026年新消息。现有短周期清理只淘汰早于下限的数据，没有上限；采集入口也只拒绝七天以前的数据，没有拒绝远未来时间。因此历史遗留的错误年份可以长期排在真正新消息之前。0.27.1的CNBC新内容即使已经采集，也不能越过这些伪未来记录。

## 决定

1. `published_at`只允许处于“当前时间前七天至当前时间后二十四小时”范围；保留一天容差以兼容时区或上游时钟小幅偏差。超过一天的未来日期在入库前拒绝。
2. ADR-0010清理条件增加同样的未来上限。服务每次启动和每轮采集结束都会删除伪未来条目及其级联证据、翻译、缩略图和通知引用；正常当前消息和主人Web Push订阅不受影响。
3. 不尝试凭标题替旧稿猜年份，也不把1997年改写成2026年或其他年份。错误记录直接从短周期热点库移除；如官方Feed以后按正确发布时间重新提供，则按正常规则重新入库。
4. 当前查询排序和五分钟调度保持不变。Google退避与CNBC直连继续执行；本修复只消除挡在真实新消息前面的时间污染。
5. 不读取或绕过主人登录凭据，不直接操作Git外生产数据库。正式发布重启时由既有应用生命周期在`instantai`服务账户下执行可审计清理。

## 验证与发布门禁

- 回归样本使用截图同名SEC旧稿，并把其错误时间设置为当前时间后66天；清理预览可识别，执行后删除。当前时间后23小时仍允许，后2天拒绝入库。
- 完整254项Python测试、Python编译、10项前端契约、6项评论模块测试、TypeScript/Vite 0.27.2构建、静态资源同步和npm 0漏洞审计通过。
- 产品所有者此前明确要求完成本次“修复并发布”；0.27.1仍未解决截图问题属于同一故障未闭环。正式发布结果待固定发布器完成后补记，不把候选测试冒充生产页面已恢复。

## 回滚

回退应用会停止未来上限检查，但已经由短周期策略清掉的伪未来热点不会恢复；这些记录是时间错误的1997年旧稿，不属于正式长期档案。回滚不得恢复错误年份、改动主人凭据或触碰其他系统。
