# ADR-0095：重点事件按需汉化、Chrome中文阅读与政策提醒

- 日期：2026-11-24。
- 状态：IMPLEMENTED / ISOLATED_TESTED / NOT_RELEASED。
- 授权：所有者要求调整即时AI“重点”导航板块，解决英文事件看不懂、iPhone外链进入Safari的问题，并高度关注加息、降息、美联储政策。
- 范围：现有即时AI仓库、单主人登录及短期库；不修改或发布罗盘、北京采集器、模型下载器或社区。

## 已定位的问题

WatchEventsPanel三组标题（罗盘同步事件、官方日程、利率政策线索）没有接入VisibleTitleTranslation，原链接也没有使用已有Chrome交接机制。此前新闻标题的汉化和原文Chrome入口不会自动覆盖该面板。

另查明通知先使用普通新闻评分判定，之后lock_policy_entry才将政策消息升至90分；更新后的重要度没有进入首次通知判断。CNBC现有来源仍是信任等级3、仅标题/日期/链接发现渠道，一般新闻通知要求等级4，所以政策卡出现并不意味着手机提醒已入队。

## 决定

1. 新闻与重点事件共用一个前台可见标题协调器、一次一个请求、同题去重、原位更新、后台停止后续及失败不自动重试。只处理完整标题，不翻译/上传事件备注、报告、正文、投资资料或来源URL。英文、韩文及含明确英文经济/会议主题的中英混排可译，中文专有名词缩写不因为出现Microsoft/OpenAI等就重复计费；原题保留。
2. 新增主人认证和同源写保护下的POST `/api/watch-events/translate`。请求只提供已有事件类型/标识和预期原题，服务端从当前资料解析真实标题，拒绝客户端任意文本及过期原题。`visible_only=true`是协议标记，实际页面可见性由客户端检查，不宣称服务端能独立判断手机锁屏。
3. 继续使用既有豆包专用翻译适配器及服务器安全环境配置，不新增或读取密钥。共享50,000源字符的软件日上限、1,000 UTF-8字节输入限制、超时和错误脱敏；失败的已尝试请求计入用量，不宣称免费或已撤销计费。
4. schema17仅在原Git外SQLite增加watch_title_translations短期缓存和索引，按完整原题匹配，72小时失效，由原清理过程清除；GET重点事件只读取缓存。与原新闻译文双向复用，不把日程伪装成新闻条目，不写回罗盘事件、原判断或报告。缓存和新闻共享全局翻译锁，不新增定时翻译、外部记忆服务、用户表或运行目录。
5. iPhone/iPad的重点来源主入口为“中文阅读”：通过Chrome官方scheme把公开来源URL交给Google网页翻译（auto→zh-CN），并保留Chrome原文和普通浏览器备用。普通链接/日期/来源身份保持，拒绝凭据URL、私网地址及令牌类查询传给网页翻译；公共股票代码等普通code参数保留。其他平台使用正常HTTPS，由系统默认浏览器打开。
6. URI直接由真实用户点击打开，不先await请求或使用延迟弹窗；不在服务端抓取原站正文、预先翻译网站或读取浏览器凭据。Google翻译兼容性、Chrome是否安装、iOS实际唤起和原站限制须现场验收。程序不能替主人修改Chrome的“始终翻译”设置；原文入口可使用Chrome本身的翻译。
7. 扩充现有政策识别到联邦基金利率/基点、QE/QT、缩表/扩表和资产购买；有明确全名的已列人物可在未重复写Fed时形成待核验线索。排除仅裁员/削减成本等非利率cut用法；日历预告不混入政策结果信号。官员表态、机构预测、市场预期、纪要与决议仍分层，首发、职务、条件和事实状态交给原核验链路确认。
8. 政策提醒使用锁定后的最终重要度。仅对已有受检公开域名、有效时效、至少90分的政策候选允许等级3发现渠道进入既有提醒；保留渠道原信任等级和主人开关/更高阈值，标明“政策线索待核验”，不把媒体报道升级为官方确认。按政策标识/证据hash/通知渠道去重；原in_app/Web Push订阅、发送锁、回执及罗盘投递链路保持，不新增通知服务。
9. 重点政策卡增加六个既有优先来源的正常、延迟、暂停、失败/待首次读取状态，不回显原始错误体。继续原采集轮次（默认5分钟运行，来源各有间隔和退避），不承诺秒级或覆盖所有采访；北京时间显示不依赖设备时区。

## 证据与复用

- [Chrome iOS URI官方说明](https://chromium.googlesource.com/chromium/src/+/main/docs/ios/opening_links.md)：googlechrome/http与googlechromes/https交接。
- [iPhone Chrome翻译说明](https://support.google.com/chrome/answer/173424?co=GENIE.Platform%3DiOS&hl=zh-Hans)：原生网页翻译及用户选择始终翻译。
- [Google网页翻译说明](https://support.google.com/translate/answer/2534559?co=GENIE.Platform%3DDesktop&hl=zh-Hans)：网站翻译入口与可用性限制。只构造显式点击URL，不把URL构造测试说成iOS或全文翻译成功。
- 复用现有Python/SQLite/urllib、豆包适配器、IntersectionObserver、Chrome URI规则和原通知outbox；无新依赖或第三方源码，六仓锁定版本不变。
