# ADR-0043：模型先生新视频到达即自动识别原文并提炼关键词

- 日期：2026-09-09
- 状态：`ACCEPTED_DEVELOPMENT_COMPLETE_RELEASE_PENDING`
- 目标版本：0.21.4
- 决策者：产品所有者

## 背景与根因

北京模型下载器已经把模型先生视频经既有签名传输送达新加坡，模型先生资料库也已经成功接收视频与评论，但新作品没有自动生成视频原文和 AI 关键词。逐层核对证明断点不在北京采集、HTTPS 传输或豆包接口，而在即时 AI 的模型先生处理入口：0.20.0 按 ADR-0036 把自动开关默认设为关闭；关闭时 `complete` 回调直接放弃创建任务，之后再开启也没有补偿扫描。因此视频可以在页面出现，却从未进入豆包队列，看起来像“识别没有反应”。

所有者现明确要求：模型先生视频只要送达，就自动执行豆包原文识别和 AI 关键词提炼，不需要逐条手动操作。

## 备选方案

1. 继续要求主人逐条点击：费用边界最保守，但不满足明确需求，也继续保留漏单风险。
2. 只把默认开关改为开启：未来正常回调可处理，但重启、数据库短暂失败和当前已经漏掉的视频仍无法恢复。
3. 默认自动处理，并保留即时回调、持久补偿游标和有界升级恢复：满足自动化要求，也能用去重、额度和重试边界控制费用与故障风险。

采用方案 3。

## 决定

1. 模型先生自动处理策略版本升级为 1，默认启用。第一次创建队列或把旧版队列迁移到策略 1 时，写入持久设置；迁移完成后主人仍可使用“紧急暂停”，且明确暂停会跨重启保留，不会被每次启动重新打开。
2. 北京传输 `complete` 回调仍是最快入口：作品投影完成后，立即按模型先生作品 ID 与视频 SHA-256 创建唯一到达任务。自动任务依次执行“复用已有原文或豆包 ASR → 保存原文 → 复用已有关键词或豆包文本提炼 → 保存关键词”。
3. 后台单工作者每三秒从 Git 外传输账本补偿核对 `current + accepted + transport_completed + verified MP4` 的模型先生记录。设置表保存开启边界和成功游标，并保留一秒重叠；队列唯一键保证回调重放、重复扫描和进程重启不会重复建立同一媒体任务。
4. 为恢复本次旧默认关闭策略造成的当前漏项，策略 1 首次迁移只把边界回退 48 小时。它不扫描完整历史作品库；后续主人暂停再恢复时以恢复时刻建立新边界，不补做暂停期间内容。
5. 补偿记录必须与模型先生投影映射中的来源作品、精确修订和媒体摘要完全一致，并确认私有媒体文件存在。若传输已完成但投影尚未就绪，游标停在该记录之前，下一轮继续核对，不把漏项越过去。
6. 缺少豆包配置属于付费调用前的安全停点。语音与文本配置恢复后，自动任务可以从 `configuration` 重新排队；不明确的远端调用仍进入 `review`，永不自动重试，必须由主人核对调用记录后单条确认。
7. 原安全限制全部保留：每日上海时区最多 20 次模型调用、单视频最多 20 分钟、模型先生与普通博主共用串行提供器锁、成功付费结果先缓存后落正式资料、连续三次异常暂停自动出队。已有人工原文、已有关键词、评论、标题、解读、评股和视频均不覆盖。
8. 主人页面进入模型先生时立即读取轻量处理状态，直接说明自动两步流程、执行器存活和最近检查时间；不再要求先点“查看设置”。逐条手动识别/提炼仍作为异常修复入口，但不是新视频的正常流程。

## 数据、安全与费用边界

- 队列、设置、调用计数和传输账本继续位于 Git 外私有 SQLite；视频、原文、关键词、凭据和模型响应不进入 Git。
- 补偿扫描只读本机传输元数据和摘要，不打开评论正文、不访问外网，也不产生模型费用；只有唯一队列任务进入既有豆包阶段才可能计费。
- 自动保存原文继续标记 `doubao-auto-unreviewed`；MCP 可读取但返回未人工核对语义，不把机器结果冒充主人确认。
- 本决定只改变新加坡即时 AI 的模型先生处理策略，不修改北京采集器生产代码、普通博主策略、财经新闻库、统一 MCP 权限或时变罗盘。

## 验收

- 无队列数据库时，状态接口显示策略默认开启但只读请求不创建文件；真实到达会创建唯一任务。
- 旧版关闭队列只迁移一次并启用 48 小时恢复；迁移后主人暂停，重新构造处理器或重启仍保持暂停。
- 漏回调的近期已验证视频可由补偿扫描入队；重复扫描只保留一条任务；尚未投影的完成记录不会被游标跳过。
- 自动任务完整保存豆包原文和 AI 关键词；已有原文/关键词不调用对应模型且不覆盖。
- 配置停点可在配置恢复后自动继续；`review`、配额、串行锁、连续失败和中断付费调用保护继续通过回归。
- 页面初次刷新即读取并展示自动状态，无需逐条点击。

## 替代关系与回滚

本决定替代 ADR-0036 中“模型先生自动处理默认关闭、须页面一次开启、无历史补偿”和 ADR-0033 中“不自动触发模型先生处理”的局部条款；ADR-0036 的额度、保存、去重、串行、人工核对与模糊付费结果不重试条款继续有效。ADR-0039 仍只约束普通博主，不因本决定改变。

回滚前先在主人页紧急暂停。回滚应用代码不得删除 Git 外队列、原文、关键词或调用记录；任何 `running/review` 任务先核对供应商调用记录，不清空后盲目重跑。
