# ADR-0021：模型先生独立精简模块与云端只读快照

> 状态：作品索引、投资思路和模块独立性继续有效；“不含视频、原文和评论”的范围已由用户新要求和 ADR-0022 局部取代。

- 状态：`ACCEPTED`
- 日期：2026-08-30
- 决策者：用户要求检查并清理模型先生多余内容，再作为独立功能模块接入即时 AI

## 背景

模型先生源项目位于 `H:\模型先生智能体`，本机服务监听 `127.0.0.1:8787`。盘点发现项目包含作品与投资思路，也包含粉丝社区、评论、导入、删除编辑、API 开关、日志、约 53MB 数据库和约 4.37GB 视频。原项目没有独立许可证文件，也没有适合直接公网暴露的认证层；其本机问答开关当前关闭。

## 决定

1. 不复制、重写或破坏原模型先生工程；原数据、视频和服务继续独立保留。
2. 即时 AI 只接入三个入口：作品浏览、投资思路、智能问答。隐藏粉丝社区、评论、导入、删除编辑、API 设置和所有管理操作。
3. 即时 AI 后端通过固定字段白名单清理响应；不返回本地文件路径、媒体资源路径、原始 JSON、评论数量、粉丝资料、密钥、数据库字段或管理状态。
4. 本机优先连接回环服务 `127.0.0.1:8787`；默认禁止连接远程模型先生源站。
5. 云端不上传 `.env`、原始数据库、评论、视频或日志，只上传由白名单导出的只读公开快照。快照位于 Git 和应用仓库之外，可独立替换；当前只支持作品和投资思路，问答在另行安全配置模型服务前明确显示未启用。
6. 模块放在“重点事件关注”右侧；手机版底部在“重点”右边增加第七个“模型先生”入口，桌面左栏同步增加。

## 理由

该方案保留模型先生最有价值的知识入口，同时把大流量视频、隐私数据和管理能力排除在即时 AI 之外。117KB 级精简快照足以支撑云端只读展示，不需要上传 4GB 多视频或私密数据库。

## 影响

- 模型先生仍是独立功能模块，不与即时 AI 新闻数据库合并，也不改变三至七天新闻保留规则。
- 本机模型服务可用时显示实时作品和投资思路；服务关闭时可使用最近一次精简快照降级。
- 云端智能问答默认关闭，直到用户另行批准并安全配置模型服务和凭据；界面不得冒充已启用。
- 模型先生源项目无独立许可证文件，故不把其源代码或静态前端复制进即时 AI 公开仓库；即时 AI 仅实现独立网关和原创展示模块。
