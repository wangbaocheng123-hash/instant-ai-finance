## 决定与新授权边界

1. 本轮独立实现云端 Ark Responses 适配层，沿用本地十类契约与模型默认值，不引入新模型平台、Codex进程或账号。只发送正式原文，不发送评论、投资数据、路径或标题；超60000字拒绝，不静默截断。模型输出不是投资建议。
2. 复用既有云端豆包录音识别函数；新增可选20分钟时长检查，提取音频后、提交付费调用前执行。普通博主与原手动识别仍兼容。
3. 所有者本轮明确要求“视频推送以后自动识别，不逐条点击”。据此局部替代 ADR-0022/0033 中模型先生禁止自动处理的旧约束：主人在页面一次确认开启后，仅对随后收到的模型先生 complete 事件入队，后台串行自动识别、保存、提炼。不扫描历史库，不为普通博主改变计费策略，不采集抖音。
4. 自动开关默认关闭，运行设置与队列位于模型先生 Git 外 `processing.sqlite3`，不进入新闻库。每日上海时区最多20次调用预留（含失败预留），每视频最多20分钟；两项都缺失时最多处理约10条。达到额度只等待次日，连续三次异常停止自动出队，主人可以暂停或确认后恢复。
5. 已有正式原文绝不覆盖；优先复用已保存豆包转写。成功付费结果先写私有队列再写正式资料，避免保存失败后重复付费。关键词已有内容或已有确认标记时自动流程跳过；手动提炼须确认费用，原文未变且版本匹配时复用已存结果。
6. 任务去重、进程级单工作者锁及手动/自动共享识别锁保护并发。服务重启将中断任务标为待核对，绝不假定上次远端调用未发生；失败与缺配置不自动重试，主人核对后可单条重试。已完成任务不可重试。错误只保存固定状态，不泄露上游响应。
7. 自动保存来源为 `doubao-auto-unreviewed`：作为可检索的作品原文保存，但 MCP 返回 `verified=false`，不冒充人工确认；主人核对后手动保存恢复原有确认语义。五个只读 MCP 工具不新增写能力、也不触发处理。
8. 主人页提供配置布尔状态、开关、最近任务、重试和单条豆包关键词按钮。查看状态只读，不创建库、不调用模型、不轮询所有原文；刷新状态不覆盖编辑草稿。任务完成后收起并重开作品查看新结果。

## 配置与正式启用

- 继续使用既有 `INSTANT_AI_DOUBAO_ASR_*` 语音配置与 ffmpeg。
- 新增服务端 `INSTANT_AI_DOUBAO_ARK_API_KEY`；可选 `INSTANT_AI_DOUBAO_TEXT_MODEL`，默认与本地状态一致。
- 文本密钥只能由既有安全运维流程注入 Git 外 root 0600 服务环境文件。不读取/复制本地 `.env`，不把语音密钥当文本密钥，不在前端设置或展示密钥；本轮没有配置真实凭据。
- 2026-09-04 配置入口补充：旧语音脚本只接受 ASR 字段并会重启，故新增主人交互脚本 `deploy/aliyun/configure-model-mr-text.py`。隐藏输入两次，只新增独立文本环境文件及 drop-in，现有目标/链接/管道/密钥参数一律拒绝；不读原配置、不重启或调用模型，仅 daemon-reload。它不是发布器，不增加 compassdev 的 sudo 白名单。新文件是否存在只查目录元数据，不能据此声称密钥有效。
- 缺文本配置时自动识别成功的原文先保存，关键词阶段明确停在“缺少配置”。配置完成后主人从队列重试该条即可复用已保存原文。
- 需另行明确正式发布，并做一个新作品的真实端到端/计费验收。本轮仅模拟请求、隔离数据和手机浏览器测试，不发布、不改生产资料、DNS或时变罗盘。

## 回滚

先在主人页暂停自动处理，再按现有发布流程回滚应用。不得删除 Git 外原文、关键词、媒体或队列；旧代码仍可读取新增的正式原文和关键词。队列中的未知远端结果必须人工核对，不允许自动清空后重跑。
