# ADR-0073：榫卯社区原仓库发布器恢复经验证的GitHub归档回退

- 状态：`ACCEPTED / LIVE`
- 日期：2026-10-15
- 决策者：产品所有者

## 背景

社区发布源回切到`instant-ai-finance`后，发布器保留了直接Git拉取，但没有带回独立仓库发布器已有的GitHub API/codeload回退。0.3.6首次发布请求在切换前因北京到GitHub的TLS传输失败退出128；旧0.3.4服务、数据库及并列进程均未变化。同期官方GitHub API可用，说明应恢复有界、可验证的官方归档回退，而不是绕过生产分支或手工替换应用文件。

## 决定

1. 直接Git拉取限制为45秒，并保留低速失败边界；成功时仍使用裸仓库、快进检查和社区子树Git对象。
2. Git拉取失败时，只通过官方GitHub API解析`sunmao-production`精确提交，校验其为已接受提交的快进，并逐层解析`services/sunmao-ai-community`子树摘要。
3. 只下载目标提交的不可变codeload归档，并只解包社区子树；拒绝路径穿越、特殊对象、敏感运行文件、超大归档和缺少必需文件的内容。
4. Git与归档两种来源随后使用同一隔离测试、release标记、原子符号链接切换、社区进程重启、版本健康检查及失败回滚。发布器不引用、停止或重启采集器和模型下载器。

## 证据

- 发布器Bash语法、完整28项社区测试和部署契约通过；北京安装文件与原仓库文件SHA-256一致。
- 最终发布日志明确记录Git失败后切换官方API/codeload、解析提交`15bbb4c3929ac4ed5b1d7032e6aca5b866cc5546`并成功部署社区子树`28d502683211b15f416746ec720e2c3b02e6294b`。
- 发布器为`Result=success`、`ExecMainStatus=0`；北京回环和公网均返回0.3.6、目标提交及部署时间`2026-10-15T10:36:12Z`。
- 采集器InvocationID`1fe57d8cdcb744b5a1d9c934b1867a27`和模型下载器InvocationID`da82cc9fa476410ca7cc535d6e3a7127`前后不变；只重启社区。

## 影响与撤销

这项回退提高北京到GitHub Git传输抖动时的可发布性，但不改变“明确授权后才推进生产分支”的门禁，也不引入定时轮询或第二发布源。若官方API或归档校验失败，发布器必须在切换前停止并保持旧版本；不得降级为未经验证的本地复制。
