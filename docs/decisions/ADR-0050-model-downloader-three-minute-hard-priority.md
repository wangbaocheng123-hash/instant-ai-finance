# ADR-0050：模型下载器三分钟视频硬优先调度

- 状态：`ACCEPTED / IMPLEMENTED IN MAIN / PRODUCTION PENDING`
- 日期：2026-09-11
- 决策者：产品所有者

## 背景

ADR-0049 已把主页扫描、新视频下载与评论维护彻底拆开，并修复旧进程继承一次性代理后
持续扫描失败的问题。所有者随后考虑到固定一分钟全天访问可能增加平台限流或登录验证风险，
明确要求正式版本保持三分钟检查，同时保留全部视频硬优先和失败验收能力。

## 决定

1. 模型先生主页全天 24 小时运行，以每次主页检查的开始时间为基准，每 3 分钟开始下一次
   检查；不再使用旧版“整轮完成后再等三分钟”的方式。
2. 若主页扫描或新视频下载超过 3 分钟，完成视频工作后立即开始下一次主页检查，不追加等待。
3. 主页扫描和发现后的完整视频下载继续构成独立硬优先轮次，期间绝不执行评论、修复或其他
   维护任务。
4. 评论和修复每个空档最多处理一项，预留 8 秒释放浏览器，到截止时间取消并为视频让路；
   视频扫描失败时不执行维护。
5. 两个模型 systemd 单元继续显式清除大小写 HTTP/HTTPS/ALL proxy。正式发布必须在新进程
   启动后观察到晚于发布标记的真实成功主页扫描，不能只凭进程 active 判定成功。
6. 版本为 `0.9.2+git.video-priority-3m`。ADR-0050 只替代 ADR-0049 的一分钟间隔和相应
   风险判断，其余视频硬优先、维护让路、代理隔离及发布门禁全部继续有效。

## 边界

- 三分钟是降低持续访问强度后的业务折中，不承诺能够恢复发布后不足三分钟即删除的作品。
- 不并发使用共享浏览器 profile，不通过增加账号、IP 或代理绕过平台限制。
- 本决定不修改北京博主采集器、新加坡即时 AI、时变罗盘、业务数据或采集定时器。
