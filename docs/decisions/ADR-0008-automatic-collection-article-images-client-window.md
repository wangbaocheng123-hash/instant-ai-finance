# ADR-0008：自动持续采集、新闻原图与合适尺寸客户端窗口

- 状态：`ACCEPTED`
- 日期：2026-08-24
- 决策者：用户明确纠正“不是立即采集，而是一直自动运行”，并要求新闻原图和非全屏客户端窗口

## 背景

0.5.0 界面仍保留“立即采集”按钮，容易把持续运行的采集器误解为手动工具。ADR-0007 还曾为节省流量决定：只用 Feed 自带图片，无图时显示按主题生成的封面；这不满足用户所说的“新闻里边的图片”。Edge 应用壳也会复用上一次接近全屏的窗口状态，不符合普通客户端的打开效果。

## 决定

1. 删除客户端的“立即采集”按钮、点击逻辑和公开手动采集接口。服务每次启动后立即自动采集一轮，随后每 5 分钟持续采集；状态接口明确返回 `mode=automatic` 和间隔，界面只显示自动运行状态。
2. 新闻缩略图按以下顺序取得：Feed/列表明确提供的图片；新闻正文声明的 `og:image`、Twitter image、`image_src` 或 NewsArticle JSON-LD 图片；Google News 发现条目对应的公开新闻结果预览图。
3. Google News 预览索引只在用户实际看到缺图新闻时按来源加载，结果在进程内缓存 5 分钟；某来源采到新条目时立即使该来源索引失效，已有索引缺少当前新闻 ID 且已超过 1 分钟时允许主动刷新。失败状态同样在 5 分钟后重试，并以来源级锁限制并发刷新；取得的每条真实图片继续写入 `H:\即时AI文件库\cache\thumbnails`，避免重复下载。
4. 图片仍采用延迟加载。远程图片单张最多 1.25 MB、最多 3 个并发；正文元数据发现最多读取 650 KB，Google News 结果索引最多读取 5 MB、最多 2 个并发。所有跳转和图片请求继续拒绝回环、私网、保留地址、凭据 URL 和非常用端口。
5. 找不到或无法安全下载新闻原图时，只显示中性灰色“暂无新闻原图”，不再使用 AI、黄金、矿业等主题插画，避免让占位图看起来像新闻内容。
6. Edge 继续使用无地址栏的应用模式，但启动器根据 Windows 工作区计算居中窗口，当前屏幕上限为 1240×820。即使 Edge 复用旧窗口，启动器也会恢复并重新设置窗口尺寸，不再默认最大化。
7. 本决定不新增 Windows 开机启动或系统服务；“持续运行”指即时 AI 本机服务启动后持续自动工作。开机后仍由桌面快捷方式启动。

## 理由

这一方式使交互语义与实际运行方式一致，并把额外网络请求限制在用户正在阅读的新闻。新闻发布方通常用 `og:image` 或 Article/NewsArticle 结构化数据标记与文章对应的代表图片；使用这些声明比任意抓取正文第一张图片更准确。Google News 发现链接无法直接当作发布方正文，因此只读取其公开结果页中与同一条新闻 ID 对应的预览图，不绕过付费墙，也不抓取受限正文。

## 影响

- ADR-0007 中“不读取新闻正文图片元数据”和“无图时使用主题 SVG”的两项决定由本 ADR 替代；白底黑字、H 盘缓存、同源图片接口、安全上限和无视频边界继续有效。
- SQLite schema 保持 4；已有 `item_thumbnails` 表足以记录正文/结果页发现的候选、缓存位置和失败状态。
- 某些来源可能没有原图、拒绝机器人访问、返回超限内容或暂时断网；客户端会明确显示没有原图，新闻文字和证据链仍可使用。
- 2026-08-27 的修订把预览索引和失败重试对齐 5 分钟采集周期；无原图 HTTP 响应只缓存 60 秒并通过缩略图 URL 版本升级清除旧客户端占位缓存，避免“索引还没出现新条目时首次查看，随后被锁 24 小时”的时间窗口。
- 当前仅供本机所有者个人预览。新闻图片的版权和来源条款不因本地缓存而改变，不得把缓存当成可再分发素材库。

## 证据

- 自动调度与状态：`product/instant_ai/server.py`
- 正文/Google News 预览发现与安全缓存：`product/instant_ai/thumbnails.py`
- 客户端尺寸恢复：`product/instant_ai/launch.py`
- 展示分叉提交：`80ed6a0d8ae68efa57ff676ea48fec02641c5b7f`
- 本机验收：服务启动后自动完成第 43 次采集，970 条、20/20 来源健康、错误 0；最新 10 条新闻中 9 条返回 `article` 原图；当前共 65 张真实图片已缓存；桌面窗口实测 1240×820、非最大化。
- 2026-08-27 回归验收：第 260 次采集成功，2998 条、20/20 来源健康、错误 0；截图所示华盛顿邮报新闻及重复条目均返回 `article` JPEG；客户端首屏前 24 个封面中 20 个真实图、4 个明确无图、加载失败 0；12 项单元测试和浏览器控制台检查通过。
- Google 官方图片标记参考：`https://support.google.com/news/publisher-center/answer/9607104`、`https://developers.google.com/search/docs/appearance/structured-data/article`
