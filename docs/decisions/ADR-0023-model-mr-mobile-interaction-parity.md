# ADR-0023：模型先生手机版标题编辑与评论决策视图

- 状态：已采纳
- 日期：2026-08-30
- 决策者：产品所有者

## 背景

0.14.0 已把模型先生的视频、原文与评论安全带入即时 AI，但手机端验收暴露了三个差距：作品详情成功返回后仍残留“正在读取本地作品资料”，使正常视频入口看起来像卡死；作品标题不能手工修正；评论只有平铺正文，没有原客户端的本人互动、有效评论排行和评股视图。

## 决策

1. 作品详情加载成功后必须清除加载状态；视频元素只按用户点击创建，不自动播放。H.264 + AAC 媒体继续通过登录后的 HTTP Range 接口提供，并分别显示“已就绪”或明确错误，不跳转抖音冒充本地播放。
2. 单主人可以手工编辑作品标题。本机回环模式复用模型先生原服务的标题接口；云端模式只原子更新 Git 外 `public-snapshot.json` 与对应 `details/<id>.json`，不建立用户表、管理后台或通用内容管理系统。
3. 评论详情建立三个手机视图：
   - `本人回复`：按脱敏 `thread_key` 还原提问与回复上下文，只突出模型先生本人回复或本人点赞过的线程；
   - `评论排行`：在浏览器内按点赞、回复数和有效正文长度排序，并排除纯表情、纯语气词等低价值文本；
   - `评股`：导出时调用原智能体回环只读的股票提及接口，用其本地 A 股证券名称表生成确定性排行；不调用 AI，不产生 API 费用，模糊简称不强行猜测。
4. `评股`只保存证券名称、代码、计数、有限示例和已经重新编号的评论关联。原证券主表、评论源 ID、原始 JSON、本机路径、粉丝主页和数据库均不得进入云端或 Git。
5. 后续评论、标题和评股刷新只传索引与详情元数据。部署脚本必须先备份当前元数据并明确保持 `/var/lib/instant-ai/model-mr/media` 不变，避免每次重复上传约 1.3GB 视频。

## 结果与边界

- 评论排行是阅读辅助，不是投资建议，也不触发交易。
- 评股结果只表达这条作品评论区中被唯一识别的股票提及热度，不代表模型先生持仓、推荐或观点。
- 标题修改属于单主人运行资料，保留在 Git 外；Git 仍只保存程序、测试、部署脚本和本 ADR。
- 元数据更新失败时恢复上一个索引和详情备份；媒体目录、财经新闻库和时变罗盘不受影响。
