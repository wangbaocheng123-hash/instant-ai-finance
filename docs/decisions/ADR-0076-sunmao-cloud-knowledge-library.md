# ADR-0076：榫卯 AI 社区知识库以云端社区数据为准

- 状态：`ACCEPTED / DESIGN READY / NOT YET RELEASED`
- 日期：2026-10-16
- 决策者：产品所有者

## 背景

所有者明确要求知识资料持续扩充，覆盖尺寸、3D 模型、视频等，并由云端向访客提供，不能依赖本地电脑开机。现有交流区和统计运行在北京独立社区服务；榫卯视频与尺寸资料目前只有 Git 内的外部链接清单。Obsidian 仅可作为个人整理方式，不能充当社区线上数据源。

## 决定

1. 社区知识库的正式数据、检索和资源访问均由北京 `sunmao-ai-community.service` 承担；两个社区域名访问同一份北京数据。保留 ADR-0067 至 ADR-0069 的独立进程、端口、数据目录和发布边界。
2. 结构化资料与检索元数据进入现有 Git 外 `/var/lib/sunmao-community/community.sqlite3`；需要托管的文件进入 `/var/lib/sunmao-community/knowledge/`，按 `incoming`、`originals/{documents,images,models,videos}` 和 `derived` 分区，具体契约见 `services/sunmao-ai-community/docs/CLOUD_KNOWLEDGE_LIBRARY.md`。代码发布目录与数据目录继续分离。
3. 资料条目采用稳定 ID、版本、来源、审核状态与资源关联。尺寸必须记录单位、适用条件和出处；AI 可以起草，但未经确认的工程数字不发布。公开检索只使用已发布内容，文件通过受控 API/对象键访问，不公开原始目录。
4. 现有抖音/微信外链清单作为来源索引保留；第三方视频不因建立知识库而自动下载或托管。所有者有权发布的自有文件可以进入云端资源区，3D 原件与网页预览分开管理。
5. 首期复用社区服务器的持久目录，后期大媒体可以迁到社区专用云端对象存储，资料 ID 和公开 API 不变。Obsidian 可作草稿编辑器，但不参与访客请求。
6. 这是架构与目录契约决定，尚未创建生产知识目录、迁移现有资料、开放上传或启用 AI。实施和正式发布继续遵守现有社区任务与发布规则。

新加坡云端智能体接收、分类和发布新资料的操作约束见 ADR-0077。

## 验收方向

- 关掉所有者电脑，已发布资料仍可从两个社区域名检索并打开。
- 草稿、临时上传和非公开原件无法经公开 URL 访问。
- 已核实尺寸能够回溯到具体来源；证据不足时不生成确定数字。
- 代码发布和回滚不删除社区 SQLite 或知识原件；备份能同时恢复目录数据与其引用的文件。
- 知识库部署不改写或重启北京博主采集器、模型下载器、新加坡即时 AI、时变罗盘或 MCP。
