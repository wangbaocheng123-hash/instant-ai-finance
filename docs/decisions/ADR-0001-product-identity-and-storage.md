# ADR-0001：产品身份与业务文件库存储边界

- 状态：`ACCEPTED`
- 日期：2026-08-23
- 决策者：用户

## 背景

项目需要在进入开源尽调和正式实施前固定产品身份与数据边界，避免后续代码、数据库、原文证据和临时产物混放，也避免不同任务对项目名称和目标平台产生漂移。

## 决定

1. 产品正式名称为 `即时 AI`。
2. 第一目标形态为 Windows 桌面客户端。
3. 正式业务文件库根目录为 `H:\即时AI文件库`。
4. 研究仓库保存代码、文档、脚本和配置模板；H 盘文件库保存原始资料、证据、数据库、导出、备份、缓存和日志。
5. R0 完成前不选择具体桌面框架，不创建正式数据库。

## 影响

- 后续架构与运行验证必须检查所有业务写入路径，防止落到 C 盘仓库。
- `.gitignore` 必须排除数据、数据库、日志、密钥和构建产物。
- 备份策略需要在产品阶段覆盖 H 盘文件库，但缓存和日志可采用不同保留策略。
- 如需改变名称、平台或根路径，必须由用户明确批准并以新的 ADR 替代本决定。

## 尚未决定

桌面技术栈、最终数据库、H 盘内部正式数据模型、是否使用 Docker/WSL、是否提供云同步均等待 R0 研究和后续批准。
