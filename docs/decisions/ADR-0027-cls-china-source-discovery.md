# ADR-0027：财联社官网与公众号公开文章发现

- 状态：`ACCEPTED`
- 日期：2026-08-31
- 决策者：产品所有者要求把财联社公众号加入“中国财经”新闻源

## 背景

即时 AI 原有“中国财经资讯发现”是综合搜索源，不能单独辨认、停用或审计财联社。财联社官网可通过公开新闻搜索稳定发现最新标题；微信公众号“财联社”（ID：`cailianpress`，公开账号标识：`Mzg5MzEyNzEwNQ==`）没有无需登录的官方文章列表 Feed。微信账号主页要求在微信客户端内打开，搜狗微信公开搜索在验证日返回的是 2020—2023 年旧结果，不能冒充实时采集。

财联社[版权声明](https://www.cls.cn/our?nav=copyrightNotice)同时明确限制未经授权复制、展示或使用其内容，因此本系统不能把能访问网页等同于获得全文复制权。

## 决定

1. 新增“财联社官网公开新闻发现”，通过 Google News 的 `site:cls.cn when:2d` 中文公开搜索 Feed 发现标题、发布日期和跳转链接，固定归入“中国财经”。该来源可信级别为 3，属于发现线索，不作为监管或上市公司第一手公告。
2. 新增“财联社公众号公开文章发现”，读取无需登录、`robots.txt` 允许访问的公开账号索引页，只解析账号名、文章标题、日期和索引链接。该来源可信级别为 2，低于官网；索引服务故障或账号身份不匹配时，单独标记来源错误，不影响官网及其他来源。
3. 两条来源均启用 `title_link_only` 和 `discovery_only`：不下载微信公众号正文，不保存财联社正文摘要，不携带 Cookie，不登录微信，不处理验证码，不绕过访问限制，也不调用需要 Cookie 或第三方私密令牌的 RSSHub 路由。
4. 两条来源继续使用统一五分钟采集、跨轮次幂等、来源证据和 ADR-0010 的短期淘汰策略。超过七天的旧条目在入库前拒绝；普通消息最多保留 72 小时。
5. 公众号索引只是“这篇文章由该账号发布”的发现证据。涉及投资判断时仍须打开财联社/微信原文，并与交易所、监管机构、上市公司公告等第一手来源交叉核验。

## 未采用的方案

- 不使用微信登录态、公众号后台 Cookie、个人微信抓包或验证码绕过：安全性和长期稳定性不符合单主人产品边界。
- 不使用搜狗当前结果：实测结果陈旧，无法满足即时热点要求。
- 不使用抓取财联社 API 并复制全文的 RSSHub 路由：这会扩大转载和授权风险，也把易变反爬逻辑带入主进程。
- 不把公众号索引提升为官网同级可信度：索引是第三方发现通道，不是财联社官方 API。

## 影响与退出条件

- 默认来源由 20 个增加到 22 个；新增条目只进入“中国财经”，仍可因标题内容同时命中黄金、AI、宏观等主题。
- 公众号索引站点一旦停止更新、改变结构、禁止抓取或无法提供可核验日期，应停用该来源并保留官网源，不能静默改用更高风险方案。
- 若财联社或微信未来提供明确授权的官方 Feed/API，应新增决策记录，把公众号来源迁移到官方通道并移除第三方索引。
