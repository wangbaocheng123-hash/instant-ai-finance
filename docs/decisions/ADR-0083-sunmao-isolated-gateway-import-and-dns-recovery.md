# ADR-0083：社区独立网关配置与备案后入口恢复

- 状态：英文服务器配置已修复；两域DNS及普通公网验收待完成。
- 日期：2026-11-09。
- 关系：补充ADR-0069，不改变社区独立应用或Git外数据位置。

## 事实

所有者确认中文域名备案通过，并授权本次使用右侧阿里云页面。北京社区仍为0.3.10/0503e77，隧道健康；新加坡共享Caddyfile的11月7日更新移除了精确英文站点，造成TLS握手失败。两个根域的权威DNS查询又均无A地址，需要分别处理配置和DNS，不能把任一项成功等同普通公网已恢复。

## 决定及实施

英文站点独立保存在`/etc/caddy/sunmao-community.caddy`，由不归时变罗盘总配置管理的既有`Caddyfile.instant-ai`追加精确import加载。保持共享配置原字节、MCP块、即时AI块；不增加通配符、不改变上游或复制社区数据。脚本提供事前校验、备份、失败回滚和幂等。

Caddy 2.11.4关闭admin API，常规reload失败后已回滚文件；随后按官方信号方式平滑加载，进程标识未变。Windows和北京外部定向请求均返回同一完整SHA；中文定向北京HTTPS也正常。

中文根A预期北京47.93.214.76，英文根A保持新加坡47.236.175.118。备案通过由所有者确认；DNS恢复尚未提交，不能声称已在控制台核验备案或全部公网恢复。当前没有右侧页面点击工具，不能导出会话凭据来替代。

## 完成条件

权威DNS返回两根正确地址，普通公网HTTPS、精确版本、同一资料数据及后台保护全部通过；MCP DNS/站点保持，各业务服务不重启。详细现场步骤和备份位置见社区`deploy/singapore/README.md`。
