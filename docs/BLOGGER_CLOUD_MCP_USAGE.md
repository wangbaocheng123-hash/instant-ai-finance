# 即时 AI 资料智能体（云端）使用说明

## 结论

手机 GPT 不需要另建项目，也不需要继续使用电脑本地旧插件。正确方式是：先在同一 ChatGPT 账号中建立一次“即时 AI 资料智能体（云端）”MCP 连接，以后在手机或电脑的新对话里从工具菜单选择它。0.19.0 起，同一个连接同时查询博主智能体和模型先生。

云端连接地址固定为：

```text
https://grandpaamu.com/mcp
```

正式生产 0.19.0 已可使用该地址，并已公开两个博主工具和三个模型先生工具。

## 统一连接与交叉调用

- 已经建立“博主智能体（云端）”连接时，不需要再建“模型先生”插件；打开原连接点击 Refresh 即可发现五个工具。
- 插件或 GPT 的显示名称不决定资料权限。只要该对话或 GPT 启用了 `https://grandpaamu.com/mcp` 这一连接，就既能调用博主内容，也能调用模型先生内容。
- 因此可以先读取某位博主的观点，再查询模型先生对同一主题的作品或投资思路，也可以反向查询。它们只在 MCP 查询层相通；博主库与模型先生库仍分别存储，工具不会互相改写或复制数据。
- 如果某个自建 GPT 在配置中只允许部分工具，它只能调用被允许的那部分；这属于 GPT 自身的工具限制，不是即时 AI MCP 的限制。

## 首次连接（一次性）

1. 使用与手机相同的 ChatGPT 账号打开 ChatGPT 网页或桌面端。
2. 进入“设置 → 安全与登录”，打开“开发者模式”。账号或工作区策略没有该开关时，当前账号暂不能添加自定义 MCP。
3. 打开 ChatGPT Plugins，点击加号新增连接。
4. 名称填写“即时 AI 资料智能体（云端）”；连接方式选择公网 MCP 地址。已经建立的旧连接可保留原显示名称。
5. 地址填写完整的 `https://grandpaamu.com/mcp`。
6. 0.19.0 起，ChatGPT 应发现五个只读工具：两个博主工具和三个模型先生工具，然后保存连接。
7. 第一次查询时会打开即时 AI 授权页。主人账号由服务器当前配置自动带入且不可编辑，只需填写现有主人密码并点击“确认授权”；不要把密码发到聊天中。
8. 0.18.5 起，账号验证成功后会出现“返回 ChatGPT 完成授权”按钮。直接点击该按钮完成连接，不要复制链接、刷新页面或重复提交密码。

连接成功后无需每次重新配置。OAuth 授权默认与即时 AI 主人会话一致为 30 天；到期后再次出现授权页属于正常现象。

## 手机端使用

1. 手机 ChatGPT 登录与首次连接相同的账号。
2. 新建普通对话；“项目”可建可不建，只影响对话归类，不影响数据连接。
3. 点击输入框附近的工具/加号，选择“即时 AI 资料智能体（云端）”；旧连接可能仍显示“博主智能体（云端）”。
4. 直接提问，并明确要求调用云端博主工具。

推荐提问：

```text
请调用“即时 AI 资料智能体（云端）”，查询李爱琳rene最新一条视频，告诉我标题、发布时间和视频文字状态。
```

读取全文：

```text
请继续读取刚才那条 cloud-video: 编号对应的完整正式视频原文，并概括主要观点。
```

按主题搜索：

```text
请调用“即时 AI 资料智能体（云端）”，搜索所有博主最近谈到全球债券市场的视频，只引用已标记 official 的正式原文。
```

查询模型先生最新作品：

```text
请调用“即时 AI 资料智能体（云端）”，查询模型先生最新一条作品，并告诉我标题、发布时间和原文状态。
```

读取模型先生完整文字与已有解读：

```text
请继续读取刚才 model-mr-work: 编号对应的完整视频原文和已有投资解读；如果是未确认转写，请明确标注。
```

查询模型先生投资思路：

```text
请调用“即时 AI 资料智能体（云端）”，列出模型先生与周期判断有关的投资思路分类。
```

模型先生 MCP 只读取作品元数据、正式原文或明确标记的未确认转写、已有投资解读和投资思路索引。它不返回评论、媒体文件或本机路径，也不执行标题修改、下载、识别、豆包、AI 问答或任何写入。

## 旧插件与新插件的区别

- “博主智能体”旧连接：读取 Windows 电脑本地历史库，需要电脑及本地 MCP 在线；此前实测查询李爱琳最新视频返回了旧的其他博主内容。
- “即时 AI 资料智能体（云端）”：直接读取新加坡即时 AI 的最新博主资料；0.19.0 起也读取模型先生作品文字、已有解读和投资思路，手机不依赖电脑开机。

为了避免选错，保留 Windows 旧连接时应把它重命名为“博主智能体（本地历史）”。日常手机查询选择云端连接。

## 常见问题

- 看不到插件：先确认手机与电脑是同一 ChatGPT 账号；自定义插件可用性还可能受账号或工作区策略限制。
- 工具列表没有更新：在 ChatGPT Plugins 中打开该连接并点击 Refresh，然后新建对话。
- 0.19.0 发布后仍只看到两个工具：先点击 Refresh；服务器继续兼容原 `blogger.read` 授权，因此已有有效连接不需要为了模型先生再输入一次密码。
- 出现需要授权：使用即时 AI 现有主人账号完成一次授权，不要创建新用户。
- 点击确认后又回到同一页面：不要连续尝试密码。0.18.3 起可由云端 Codex 从服务器回环读取不含凭据的阶段标记，区分凭据拒绝、已发出回调、token 失败或 token 已签发；公网无法读取该诊断快照。
- 若诊断显示稳定回调已发出但没有 token 请求，0.18.4 起应删除该失败外壳并新建连接；新连接会按 OpenAI 官方 callback-ID 兼容模式使用独有回调地址，不能复用旧授权页面或旧客户端。
- 若 0.18.5 授权页显示“账号验证成功”，说明即时 AI 账号密码已经通过；必须再点击“返回 ChatGPT 完成授权”，ChatGPT 才会继续交换 token。该按钮只用于当次连接，过期后应从 ChatGPT 新建连接，不要复用旧页面。
- 搜索到 `transcript_unconfirmed`：这是尚未由主人确认为正式原文的识别文字，GPT 必须明确提示，不能当作 official 引用。
- 返回空结果：先确认视频已从北京传到新加坡，且即时 AI 博主页面已经显示该作品及文字；MCP 本身不会启动采集或豆包识别。
