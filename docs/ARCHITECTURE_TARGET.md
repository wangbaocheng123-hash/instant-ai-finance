# 目标架构假设（待 R0 验证）

本文件不是最终设计。所有条目均为 `HYPOTHESIS`。

已固定边界：单机、单用户、无账户体系。架构中不得出现用户表、注册/登录、个人资料、团队、角色、权限、租户或管理员服务。

```text
授权信息源
  → 采集/变化监测
  → 标准化与证据保存
  → 去重、实体识别、事件分类
  → 重要度评分与 AI 分析
  → 本地数据库/全文检索
  → Windows 桌面客户端
  → 本机所有者可控的报告与推送
```

待验证边界：TrendRadar 是否可作主底座、RSSHub 与 changedetection 是否作独立服务、OpenBB 是否作数据提供器、n8n 是否值得引入、Folo 是否仅作 UI 参考，以及桌面壳和数据库的最终选择。

所有业务数据必须落在 `H:\即时AI文件库`；仓库仅保存代码和配置模板。
