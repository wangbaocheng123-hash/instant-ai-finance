# 即时 AI 当前架构基线

状态：`ACCEPTED_MVP_BASELINE`。R0 假设已由 ADR-0002/ADR-0004 转化为第一版可运行实现；未来替换桌面壳或增加 sidecar 时必须保持领域和 H 盘存储契约。

已固定边界：单主人、无注册、无多用户体系。云端只允许 ADR-0020 的一个主人凭据文件与 30 天签名会话；架构中不得出现用户表、注册、个人资料、团队、角色、权限、租户或管理员服务。

```text
授权信息源
  → 采集/变化监测
  → 标准化与证据保存
  → 去重、实体识别、事件分类
  → 重要度评分与可选 AI 分析
  → 本地数据库/全文检索
  → Windows 桌面客户端
  → 单一主人登录保护的手机入口
  → 本机所有者可控的报告与推送
```

当前已实现：自有薄型核心、官方 RSS/网页采集、证据保存、SQLite/FTS、规则评分、本地 API、Edge 应用壳和桌面阅读界面。当前不依赖任何 sidecar 也能运行。

后续可选边界：RSSHub 与 changedetection 作白名单独立服务，OpenBB 作数据提供器，TrendRadar 作热点补充，n8n 作后置可选工作流，Folo 仅作 UI 研究参考；均不得直接写正式数据库或引入多用户层。模型先生按 ADR-0021 作为独立只读模块接入。

所有业务数据必须落在 `H:\即时AI文件库`；仓库仅保存代码和配置模板。
