# 即时 AI 正式产品区

状态：`LOCAL_MVP_USABLE / CONTINUING_DEVELOPMENT`。

当前 0.10.0 开发候选版是全球财经即时热点雷达：Python 标准库提供 localhost 服务，SQLite/WAL 保存当前窗口元数据，Edge 应用窗口提供桌面界面；同时包含手机响应式布局和浏览器模式主屏幕入口。新增的“重点事件关注”只读同步时变罗盘首页与紫金时间线，并用当前短周期财经消息持续匹配；不会读取持仓或交易数据。iPhone 详情页直接切换到 Chrome 打开原站，并保留普通 HTTPS 备用入口；其他设备继续使用默认浏览器。即时 AI 不抓取新闻正文，只按需翻译资讯源现有摘要作为备用。没有产品账户层，也不需要姓名、邮箱或密码。普通消息 72 小时、重要消息 5 天、最高重要度消息最多 7 天，随后自动清理。

启动入口：

```powershell
pythonw product\launch_instant_ai.py
```

桌面快捷方式已经创建，可直接双击 `即时 AI`。客户端提供即时热点、12 个财经频道、临时置顶、重要提醒、来源状态、当前证据和当前窗口搜索；不提供长期档案入口。

需要在电脑上查看手机版效果时，双击桌面的 `即时 AI（手机预览）`。它会自动启动同一个本机数据核心，并以约 460×900 的独立手机尺寸窗口打开；不会连接云端，也不影响普通桌面客户端。

短周期运行数据只写入 `H:\即时AI文件库`：

- `database\instant_ai.db`：正式 SQLite 数据库；
- `raw\`：当前窗口需要的来源原始响应；
- `evidence\`：最多 7 天的采集运行清单与当前证据；
- `backups\`：最近 3 份短期安全备份；
- `cache\`：桌面壳和可再生缓存；
- `logs\`：脱敏日志。

AI 后处理目前已完成证据包和任务边界，但尚未配置真实模型。点击“准备 AI 证据包”只会保存可审计输入并等待安全配置，不会把确定性评分冒充模型摘要，也不会阻断现有采集和阅读。

验证命令：

```powershell
scripts\verify-instant-ai.ps1
```

代码、测试和已构建静态界面保留在本目录；可修改前端源代码固定在 `client/instant-ai/`。数据库、原始证据、缓存和日志不会进入 Git。

阿里云手机伴随入口使用独立数据根目录，不上传 H 盘资料。部署边界和模板见 `deploy/aliyun/`、ADR-0009 与 ADR-0011；公网入口经过 HTTPS，但不增加账户或密码，也不能直接开放 Python 的 `18765` 端口。
