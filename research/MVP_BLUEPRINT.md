# “即时 AI”MVP 蓝图

状态：`LOCAL_MVP_USABLE / IMPLEMENTATION_CONTINUES`。正式实现和运行选择见 ADR-0004；本文件继续作为范围与验收蓝图。

## 产品边界

第一版为电脑所有者本人建立全球财经即时热点闭环：覆盖全球/华尔街、中国/亚洲、AI 产业链、紫金矿业、黄金、铜和有色金属、宏观央行、地缘供应链、融资并购和财经知识，从公开来源收集文字信息及轻量图片预览，在短周期窗口内保留证据、去重和评分，并只推送真正重要的变化。2026-08-28 起增加本人使用的手机云端伴随入口；系统仍不识别“用户”，H 盘与云端都不是长期资料库。

不做自动交易、自动买卖建议、付费墙绕过、全网爬虫、社交平台账号自动化、产品账户体系、个人资料、多人协作或 H 盘正式资料的云同步。手机版是单一所有者的独立采集副本，不是多用户服务。

## H 盘数据布局

```text
H:\即时AI文件库\
  raw\              # 当前窗口原始响应，按内容 hash 保存并自动清理
  evidence\         # 最多 7 天的证据和运行清单
  database\         # 当前窗口 SQLite/索引
  cache\             # 可删除的 sidecar/provider 缓存
  exports\           # 兼容目录；产品不提供长期导出入口
  backups\           # 最新 3 份短期安全备份
  logs\              # 脱敏运行日志
```

密钥不进入 H 盘普通配置或 Git；候选方案是 Windows Credential Manager/DPAPI。上游 sidecar 使用各自隔离子目录，不能直接写 `database` 正式区。

## 推荐数据流

```text
Source registry
  -> adapter fetch/change/query
  -> Evidence envelope(URL, fetched_at, status, hash, raw locator, terms tag)
  -> deterministic normalization/dedup
  -> entity extraction(company/commodity/industry/policy)
  -> event classification
  -> explainable rule score
  -> optional AI classification/summary with evidence citations
  -> current-window database + full-text index
  -> inbox/timeline/detail
  -> notification outbox -> approved channel
  -> lifecycle cleanup (72h / 5d / 7d)
```

AI 不负责延长消息寿命；当前事件证据先落地，随后与消息遵守同一生命周期。AI 结果必须记录模型、模板版本、证据 ID、时间和成本，本机所有者可以看到“为什么重要”。

## 第一批数据源

1. 紫金矿业官网、交易所/监管披露和官方公告页面：Feed 优先，无 Feed 才用 changedetection。
2. 中国证监会、上交所/港交所等与目标公司和行业相关的授权公告/Feed；RSSHub 中已定位的 CNInfo、SSE 等财经路由只能在逐路由核验后启用。
3. 与黄金、铜、宏观政策相关的政府、央行、统计/监管机构公开页面或 API。
4. OpenBB 首批只验证 SEC、FED/FRED、BLS、CFTC/EIA 等权威 Provider；它们是海外宏观/监管补充，不代替中国市场来源。
5. TrendRadar 热榜作为发现线索，必须回链到原始来源，不能直接成为最高可信证据。

每个源启用前记录授权/条款、更新频率、原始 URL、字段、速率限制、保存权限和失败策略。

## 当前界面

- 顶部单栏：“即时热点”把按发布时间排序的最新消息与服务器从完整 72 小时窗口算出的多来源热点交错去重；点击可看当前证据，不加载直播媒体，也不依赖外部热榜 API。
- 新闻卡片：白底黑字；左侧优先显示 Feed、新闻正文元数据或 Google News 同条新闻的真实预览图，右侧显示中英标题、来源、时间与标签；图片按需写入 H 盘可删除缓存，无原图时明确标注而不使用主题插画。Google News 预览索引与失败重试对齐 5 分钟采集周期，新条目会使旧索引失效，占位响应 60 秒后可重新检查。
- 标题汉化：英文标题可按需翻为中文并缓存到 H 盘；中文译文在上、英文原题在下，顶部开关可随时恢复原文，失败或额度耗尽不阻断阅读。
- 原文翻译：iPhone 详情页通过 Chrome 官方 URL scheme 直接把原站交给 Chrome，并保留普通 HTTPS 备用入口；其他设备使用默认浏览器。即时 AI 不抓取正文。“中文摘要（备用）”只翻译 Feed 已提供的摘要并随消息按 72 小时/5 天/7 天规则级联清理，见 ADR-0014 与 ADR-0015。
- 高密度终端：全球即时财经、华尔街与投行、中国、亚洲、黄金、紫金/矿业、铜/有色、AI/科技、宏观、地缘供应链、融资并购、财经知识 12 个频道。
- 时间线：最新优先，通过 12 个预置频道和重点事件页直接切换；0.12.1 起不显示统计概览或客户端搜索入口。
- 当前证据：原文 URL、抓取时间、来源级别、hash、命中规则、AI 引用；每条最多 5 个来源，到期一起删除。
- 主题页：上述 12 个预置财经视图。
- 来源与任务：来源开关、最近成功/失败、下次运行、数据条款标签。
- 系统状态：H 盘路径、来源、模型、通知和 sidecar 运行状态；仅在相应能力首次启用时提供最小本机技术配置，不设“账户/个人设置”页面，密钥通过系统安全存储管理。
- 运行方式：没有手动采集按钮；客户端服务启动后立即自动采集，随后每 5 分钟持续更新并执行生命周期清理。Edge 应用壳以居中、非最大化的合适客户端尺寸打开。

## 第一批确定性规则

- 公司/别名：紫金矿业及股票代码、主要子公司/项目名称。
- 商品/产业：gold/黄金、copper/铜、有色、冶炼、矿山、精矿、库存、产量、品位等词组。
- 事件：财报/业绩预告、重大合同、收购出售、停复产、事故、制裁、监管处罚、资本开支、产量指引、供需和库存变化。
- 来源权重：公司/监管/交易所 > 权威行业机构 > 专业媒体 > 热榜线索。
- 重复抑制：来源 ID/GUID → 规范 URL → 内容 hash → 标题相似簇；重复条目合并证据，不删除来源。
- 推送门槛：高可信来源 + 高影响事件 + 新信息；AI 分数不能单独触发。

## 第一阶段明确不做

- 不全量接入 RSSHub 路由、OpenBB Provider 或 n8n 节点。
- 不把六仓任何数据库当正式主库。
- 不做向量数据库优先设计；先用可解释的确定性去重和全文检索。
- 不让 Agent/MCP 获得任意网络、文件、通知或配置修改权限。
- 不构建任何产品账户、个人资料、用户偏好中心、多用户权限、原生手机 App、实时行情终端或自动交易，也不为这些能力预留 schema/API；已批准的手机版只复用响应式 Web App，不同步 H 盘正式库。
